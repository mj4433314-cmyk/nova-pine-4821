واجهة أوبتس للمطوّرين

ابدأ بـ3 خطوات

مفتاح واحد، عنوان واحد، ونماذج أوبتس كلها. الواجهة بصيغة المحادثة المعروفة، فأي مكتبة تعرفها تشتغل وياها.

العنوانhttps://api.optes3.com/v1
  1. 1

    خذ مفتاحك

    سجّل دخول بحساب أوبتس وسوّ مفتاح بضغطة وحدة. المفتاح يطلع مرة وحدة، احفظه بمكان آمن.

    خذ مفتاحك

    حتى تشتغل الطلبات تحتاج رصيد: اشحن من 5 دولار من نفس الصفحة.

  2. 2

    انسخ الكود

    حط مفتاحك بالمتغير OPTES_API_KEY وشغّل الكود. بس هذا.

    curl https://api.optes3.com/v1/chat/completions \
  -H "Authorization: Bearer $OPTES_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "optes-1.2-super-lite",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
    import os, requests

r = requests.post(
    "https://api.optes3.com/v1/chat/completions",
    headers={"Authorization": f"Bearer {os.environ['OPTES_API_KEY']}"},
    json={
        "model": "optes-1.2-super-lite",
        "messages": [{"role": "user", "content": "Hello!"}],
    },
)
print(r.json()["choices"][0]["message"]["content"])
    // Node 18+ or the browser
const r = await fetch("https://api.optes3.com/v1/chat/completions", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.OPTES_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "optes-1.2-super-lite",
    messages: [{ role: "user", content: "Hello!" }],
  }),
});
const data = await r.json();
console.log(data.choices[0].message.content);

    أي مكتبة بصيغة المحادثة تشتغل: خلي العنوان https://api.optes3.com/v1 والمفتاح مالتك.

  3. 3

    اختار النموذج

    اضغط على نموذج والكود فوگ يتبدّل له. السعر بالدولار لكل مليون توكن.

    شوف كل النماذج باللوحة (199 نموذج، بيها أكثر من 190 بدون قيود)

أسئلة سريعة

شنو الحدود؟

كل مفتاح تگدر تحطله سقف صرف يومي وشهري من اللوحة. وحسابك بيه حد للطلبات بالدقيقة وسقف صرف شهري، وأرقامك بالضبط تشوفها باللوحة بصفحة الحدود.

إذا وصلت الحد يرجعلك 429: استنى شوية وجرّب مرة ثانية. السياق وأطول رد مكتوبين على كل نموذج فوگ.

شلون الدفع؟

رصيد مسبق بالدولار، بلا اشتراك. تدفع بس على التوكنات اللي تستعملها بالسعر المكتوب. الشحن من 5 دولار من لوحة المطوّرين، وتشوف المبلغ النهائي وطريقة الدفع قبل ما تدفع.

رصيد الواجهة منفصل عن باقات تطبيق أوبتس.

تدعم الأدوات؟

إي. نماذج أوبتس هنا كلها تدعم استدعاء الأدوات، والرد المتدفق، ووضع JSON.

النقاط: POST /v1/chat/completions وPOST /v1/responses وGET /v1/models.

شنو تحفظون من طلباتي؟

سجلات الاستعمال ما بيها نص طلباتك ولا الردود. نحفظ الأرقام بس (النموذج، التوكنات، الكلفة، الوقت، النتيجة) حتى نحاسبك وتشوفها بسجلاتك.

الطلب يمر بالخوادم اللي تشغّل النموذج حتى يطلع الرد. التفاصيل بـسياسة الخصوصية.

مفتاحي بان لغيري، شسوي؟

ألغيه من اللوحة بضغطة وسوّ واحد جديد. المفاتيح تبدأ بـoptes-sk-، فإذا شفت واحد بمكان عام ألغيه فوراً.
