OPTES 1.2 기능

비교

  • 코딩과 전체 프로젝트

    파일 하나부터 완성된 프로젝트까지. 구조를 읽고, 코드를 작성하고, 테스트한 뒤 바꾼 내용을 스스로 검토합니다.

    사용 가능코딩

  • 실시간 미리보기

    만들고 있는 결과물이 실행되는 모습을 데스크톱, 태블릿, 휴대폰 크기로 확인하고, 오류는 클릭 한 번으로 고칩니다.

    사용 가능코딩

  • 컴퓨터 제어

    클릭하고, 입력하고, 창 사이를 오갑니다. 승인하기 전에는 절대 시작하지 않으며, 언제든 멈출 수 있습니다.

    사용 가능에이전트

  • 에이전트 팀

    개발자, 리뷰어, 리서처, 코디네이터가 긴 작업을 끝날 때까지 함께 나눠 맡습니다.

    사용 가능에이전트

  • 원클릭 배포

    내 컴퓨터의 프로젝트를 실제 웹사이트로. 비용을 확인하고 승인한 뒤에 진행합니다.

    사용 가능배포

  • 음성을 텍스트로

    타이핑 대신 말하세요. 말한 그대로 텍스트가 됩니다.

    사용 가능음성

  • 이미지 생성

    글로 쓴 설명을 원하는 스타일의 이미지로 만듭니다.

    사용 가능미디어

  • 동영상 생성

    아이디어나 이미지에서 시작하는 움직이는 영상.

    사용 가능미디어

  • 음성

    자연스러운 아랍어 음성, 그리고 허락하에 만드는 내 목소리의 복제.

  • 음악

얼굴

빛의 얼굴

OPTES가 하는 모든 일에는 얼굴이 함께합니다. 얼굴을 이루는 숫자 하나하나는 원본 사진에서 정확히 같은 자리의 밝기를 가져옵니다. 눈과 입은 그린 것이 아니라, 원본에 있는 바로 그 자리에 나타납니다.

얼굴은 빛의 점들로 흩어졌다가 온전한 형상으로 모이고, 다시 돌아옵니다. 그 위로 손을 움직이면 길을 비켜 줍니다.

이 장면은 지금 이 순간 브라우저에서 사진 두 장으로 그려지며, 손으로 그린 이목구비는 하나도 없습니다.

답에서 멈추지 않는 AI. 일을 끝까지 해냅니다.

OPTES 1.2는 OPTES의 최신 릴리스입니다. 오직 하나의 목적, 요청한 일을 끝까지 해내기 위해 만들어졌습니다. 원하는 것을 설명하면 계획하고, 작성하고, 실행하고, 테스트한 다음, 결과가 눈앞에서 작동하는 모습을 보여 줍니다.

첫 번째 답으로 감탄을 끌어내려고 만든 것이 아닙니다. 열 번째 단계에서도 믿고 맡길 수 있도록 만들었습니다.

자주 묻는 질문

OPTES에 관한 질문

OPTES는 무엇인가요?

OPTES(아랍어로는 أوبتس, اوبتس 또는 اوبتيس로 표기)는 당신의 언어로 일하는 AI 플랫폼입니다. 답에서 멈추지 않고 일을 끝까지 해내는 AI 에이전트로, 프로젝트 전체를 코딩하고 실행되는 모습을 미리 보여 주며, 승인 후 컴퓨터를 제어하고, 이미지·동영상·음성·음악을 생성하고, 게임을 만듭니다.

OPTES CODE 앱은 어떤 운영체제에서 실행되며, 어떻게 받을 수 있나요?

64비트 Windows 10과 11에서 실행되며, 설치 파일은 약 285MB입니다. 다운로드 링크는 이 페이지 상단의 다운로드 카드에 있습니다.

OPTES는 코딩 어시스턴트일 뿐인가요?

아닙니다. 코딩은 일부일 뿐입니다. 프로젝트 구조를 읽고, 코드를 작성하고 테스트하며, 바꾼 내용을 검토합니다. 여기에 실시간 미리보기, 긴 작업을 위한 에이전트 팀, 음성을 텍스트로 변환하는 기능, 이미지·동영상 생성, 음성, 음악이 함께합니다.

아랍어와 아랍어 방언을 이해하나요?

네. 인터페이스는 오른쪽에서 시작하고, 사용자가 쓰는 언어로 답합니다. 영어, 현대 표준 아랍어, 또는 평소 쓰는 방언으로요. 코드는 코드의 언어 그대로 둡니다.

허락 없이 내 컴퓨터에서 무언가를 하나요?

파일, 컴퓨터, 지출에 영향을 줄 수 있는 일은 모두 사용자가 선택한 승인 모드에 따라 사용자를 거칩니다. 명령 가드는 파괴적인 명령을 차단하고, 체크포인트는 파일을 안전하게 지키며, 지출 한도는 정해 둔 한도에서 유료 작업을 멈춥니다.

OPTES에 개발자용 AI API가 있나요?

네. 개발자 플랫폼은 텍스트, 코드, 비전, 이미지, 동영상, 음성, 음악, 검색을 아우르는 OPTES 모델 12종을 하나의 API와 하나의 키로 제공합니다.

OPTES는 누구를 위한 것인가요?

컴퓨터로 일하는 모든 사람을 위한 것입니다. 프로그래머, 디자이너, 콘텐츠 크리에이터, 학생, 교사, 창업가 등 많은 분이 해당됩니다. 직업별 활용 페이지에서 내 일에 맞춰 무엇을 해 주는지 확인할 수 있습니다.

연락하거나 보안 취약점을 신고하려면 어떻게 하나요?

support@optes3.com으로 이메일을 보내 주세요. 책임 있는 공개 절차에 관한 자세한 내용은 보안 페이지를 참고하세요.
