OPTES Cloud

첫 순간부터 보호되는 VPS 서버, 초 단위로 과금되는 GPU, 서버리스 추론 엔드포인트와 스토리지. 하나의 OPTES 계정, 하나의 콘솔.

모든 서버에 포함

첫 부팅부터 적용되며 별도 설정이 필요 없습니다.

  • DDoS 방어대규모 공격은 서버에 도달하기 전에 걸러집니다.
  • 엣지 및 호스트 방화벽허용한 트래픽 외의 인바운드는 차단되며, 같은 규칙이 서버 외부에도 적용됩니다.
  • 키 전용 SSH비밀번호와 root 로그인은 꺼져 있으며, SSH는 기본적으로 사용자의 주소로만 제한됩니다.
  • 침입 방지CrowdSec과 커뮤니티 차단 목록으로 무차별 대입 시도와 알려진 공격자를 차단합니다.
  • 자동 보안 업데이트매일 설치되며, 재부팅 시간대는 사용자가 선택합니다.
  • 25번 포트 차단 및 악용 격리직접 메일 발송은 차단되며, 탈취된 서버는 다른 사용자에게 피해를 주기 전에 격리되고 사용자의 접근은 유지됩니다.

위치 및 결제

서버 위치

독일, EU 내 인증된 데이터 센터. 중동까지 약 70 ms. 다른 지역은 추후 추가.

결제

주문은 채팅 요금제 잔액과 별개인 OPTES Cloud 지갑에서 결제됩니다. 충전은 미국 달러로 암호화폐를 사용합니다.
