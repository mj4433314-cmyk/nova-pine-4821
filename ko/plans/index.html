OPTES CODE 월간 요금제

이라크 밖에 계신가요? 암호화폐로 결제하세요: BTC, ETH, USDT 등. 이 페이지의 가격은 미국 달러 표시입니다. 이라크에서는: 이라크 디나르 가격.

요금제 업그레이드 이미 구독 중이신가요? 새 요금제의 전체 금액을 결제하며 남은 크레딧은 그대로 옮겨집니다.

OPTES CODE 앱의 월간 구독입니다. 모든 요금제에는 7일마다 초기화되는 주간 한도 하나와 한 달 전체 한도가 있으며, 상위 요금제일수록 한도가 크고 컨텍스트가 길며 우선순위가 높습니다.

요금제 선택Super Lite모든 요금제에 포함요금제에 관한 질문
이라크 밖에서는 미국 달러 가격을 암호화폐로 결제하며, 이라크에서는 현지 결제 수단을 통해 이라크 디나르로 결제합니다.

이 페이지의 달러 가격은 이라크 밖에서의 가격이며, 암호화폐(USDT, BTC, ETH 등)로 결제합니다. 이라크 디나르 가격은 아랍어 요금제 페이지에 있습니다.

자주 묻는 질문

요금제에 관한 질문

어떻게 결제하나요?

이라크 밖에서는 OxaPay를 통해 암호화폐(USDT, BTC, ETH 등)로, 이 페이지에 표시된 미국 달러 가격으로 결제합니다. 이라크에서는 현지 결제 게이트웨이를 통해 이라크 디나르로 결제하며 수수료가 포함되어 있습니다. 두 방식의 규칙은 이용약관에 나와 있습니다.

각 요금제에는 어떤 모델이 포함되나요?

Lite: OPTES 1.2 Super Lite(기본), 1.2 Series Lite, Murphy 1.2.5 Super X Lite, 1.2.1 Flash, 1.2 Series. Pro: 동일한 모델. Pro 2x 이상: 위의 모든 모델에 OPTES 1.2 Super와 MORPHEUS 모델 추가. OPTES 1.2.1 Flash, 1.2 Series, 1.2 Super, MORPHEUS는 요청을 덜 거절하므로 성인용이며, 18세 이상임을 확인한 후에만 열립니다.

주간 한도와 월간 한도는 무엇인가요?

주간 한도는 앱에 표시되는 정해진 시각(예: “토 오후 3:00 초기화”)에 7일마다 초기화되는 한도입니다. 한 주 동안 원하는 속도로 사용할 수 있으며, 5시간 한도나 일일 한도는 없습니다. 월간 한도는 한 달 전체의 상한입니다. 각 요청은 실제로 사용한 만큼만 계산되며, 주간 한도의 75%와 90%에 도달하면 앱이 알려 드립니다.

한도를 다 쓰면 어떻게 되나요?

작업은 멈추지 않습니다. 주간 한도나 월간 한도가 초기화될 때까지 텍스트와 코드용 가벼운 예비 경로에서 계속됩니다(주간 한도 있음).

무료로 쓸 수 있나요?

네. 무료 요금제는 휴대폰과 웹에서 채팅만 가능하며 OPTES Fast를 사용합니다. 주당 최대 420개의 메시지를 보낼 수 있고 매주 토요일에 초기화됩니다. 위의 요금제는 더 많은 사용량, 더 많은 모델, 데스크톱 앱을 제공합니다.

요금제에 API가 포함되나요?

Pro+, Max, Max Plus, Max Ultra에는 API 이용이 포함됩니다. API만 필요하다면 구독 없이 지금처럼 사용한 만큼 결제합니다. 개발자 요금을 확인하세요.

구독을 해지할 수 있나요?

네. 해지해도 결제한 달이 끝날 때까지 요금제가 유지됩니다.

라이트의 ‘휴대폰 전용’은 무슨 뜻인가요?

라이트는 대화용 요금제예요. 같은 계정으로 휴대폰 앱과 웹 채팅에서 쓸 수 있어요. 컴퓨터 앱(에이전트와 편집기), 클라우드 컴퓨터, 동영상은 포함되지 않아요. 구독은 휴대폰 앱에서 하고, 컴퓨터 앱이 필요하면 Pro 이상을 선택하세요.
