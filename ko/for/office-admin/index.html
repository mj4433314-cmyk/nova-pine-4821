사무 관리자와 비서

사무 관리자와 비서를 위한 AI 어시스턴트

사무 관리자의 책상에는 공문, 서류, 회의, 스프레드시트가 끊임없이 쌓입니다. OPTES는 기관의 양식에 맞춰 공문 초안을 쓰고, 들어오는 종이 문서를 검색 가능한 아카이브로 만들며, 회의록을 쓰고, 승인하면 시스템 사이에서 데이터를 옮깁니다. 검토와 서명, 결정은 직접 하고, OPTES는 시간을 아껴 드립니다.

Windows용 OPTES 다운로드해 드리는 일 보기

Windows 10 및 11 · 64비트

OPTES가 해 드리는 일사용하게 될 기능질문과 답변관련 직업

OPTES가 해 드리는 일

공문과 내부 메모

직접 쓴 두어 줄을 바탕으로 기관의 레터헤드 관례와 문체를 따라 공문과 내부 메모 초안을 씁니다. 서명하고 보내기 전에 검토하세요.

입력 예시

전력 공급 기관에 우리 회사 새 건물로 전력선을 옮겨 달라고 요청하는 공문을 짧고 격식 있게 써 주세요.

사용 가능글쓰기, 편집, 번역

수신 문서 보관

손으로 쓴 것을 포함해 종이 서신 사진을 읽고 문서 번호, 날짜, 발신처, 제목을 검색 가능한 아카이브 표로 추출합니다. 결과는 직접 확인하세요.

입력 예시

수신 공문 60건의 사진이에요. 건마다 문서 번호, 날짜, 발신 부서, 제목을 하나의 표로 뽑아 주세요.

사용 가능이미지와 문서 읽기

회의록

모든 참석자의 동의를 받아 녹음한 회의를 참석자, 결정 사항, 업무 배정이 담긴 공식 회의록으로 만들며, 논의가 방언으로 이루어졌더라도 표준 아랍어로 작성합니다.

입력 예시

이사회 회의를 받아 적고 공식 회의록으로 만들어 주세요. 논의는 방언으로 했지만 회의록은 표준 아랍어로 필요해요.

사용 가능음성을 텍스트로

시스템 간 데이터 입력

승인하면 OPTES가 클릭, 입력, 창 전환으로 스프레드시트의 데이터를 기관의 시스템에 옮깁니다. 지켜보다가 언제든 멈출 수 있습니다.

입력 예시

이 시트에 있는 교육 참가자들을 우리 시스템의 등록 양식에 입력해 주세요. 저장할 때마다 먼저 제 승인을 받아 주세요.

사용 가능승인 후 컴퓨터 제어

연락처 목록 정리

이름과 전화번호를 표준화하고 중복을 합치는 작은 스크립트를 작성해, 원본 파일은 그대로 둔 채 새 사본을 만들어 드립니다.

입력 예시

이 연락처 목록을 정리해 주세요. 전화번호 형식을 통일하고, 중복된 이름은 합치고, 원본 파일은 그대로 두세요.

사용 가능코딩과 전체 프로젝트

사용하게 될 기능

  • 사용 가능글쓰기, 편집, 번역글을 쓰고 다듬고 번역하며, 사용하는 언어나 방언으로 답합니다.
  • 사용 가능이미지와 문서 읽기손글씨 아랍어를 포함해 이미지와 스캔한 문서를 읽습니다.
  • 사용 가능음성을 텍스트로타이핑 대신 말하세요. 아랍어 방언을 포함해 말이 텍스트가 됩니다.
  • 사용 가능승인 후 컴퓨터 제어클릭하고, 입력하고, 창 사이를 오가며, 승인 전에는 절대 시작하지 않습니다.
  • 사용 가능코딩과 전체 프로젝트프로젝트 구조를 읽고, 코드를 작성하고 테스트하며, 바꾼 내용을 검토합니다.

자주 묻는 질문

질문과 답변

OPTES는 사무 관리자에게 어떤 도움이 되나요?

반복적인 사무 업무를 맡습니다. 공문 초안 작성, 서류 보관, 회의록 작성, 승인 후 데이터 입력, 스프레드시트 정리까지 돕습니다. 검토, 서명, 결정은 직접 합니다.

우리 기관의 공문 양식을 따를 수 있나요?

이전 공문 샘플을 주면 같은 레터헤드, 문체, 레이아웃을 따릅니다. 필요에 따라 표준 아랍어나 영어로 쓰며, 검토와 서명은 직접 합니다.

컴퓨터 제어는 안전한가요?

승인한 뒤에만 시작하고, 눈앞에서 클릭하고 입력하는 모습을 지켜볼 수 있으며, 언제든 멈출 수 있습니다. 명령 가드가 모든 명령을 실행 전에 검사해 파괴적인 명령을 차단하고, 모든 작업은 기록됩니다.

아랍어 손글씨를 읽을 수 있나요?

네. 아랍어 손글씨를 포함해 이미지와 문서를 읽습니다. 이미지가 선명할수록 결과가 정확하니, 표를 활용하기 전에 숫자와 이름을 확인하세요.
