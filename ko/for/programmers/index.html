프로그래머

코딩 전에 프로젝트부터 읽는 프로그래머용 AI 어시스턴트

OPTES는 옆에 띄워 둔 채팅창이 아니라 프로젝트 안에서 일합니다. 폴더 구조를 읽고, 기존 네이밍과 컨벤션을 따르며, 변경 사항을 작성하고 테스트를 실행한 뒤, 보여 드리기 전에 자신의 diff를 직접 검토합니다. 모든 명령은 먼저 가드를 통과하고, 비밀 정보는 에이전트에게 숨겨지며, 체크포인트로 어떤 파일이든 되돌릴 수 있습니다.

Windows용 OPTES 다운로드해 드리는 일 보기

Windows 10 및 11 · 64비트

OPTES가 해 드리는 일사용하게 될 기능질문과 답변관련 직업

OPTES가 해 드리는 일

실패하는 테스트 고치기

실패 내용을 붙여 넣거나 테스트 이름을 알려 주세요. OPTES가 코드를 따라가며 원인을 찾고, 수정안을 제안하고, 테스트를 다시 돌린 뒤 수락하거나 거절할 diff를 보여 줍니다.

입력 예시

어제 머지 이후로 test_invoice_totals가 계속 실패해요. 원인을 찾아서 테스트 자체는 건드리지 말고 고쳐 주세요.

사용 가능코딩과 전체 프로젝트

모듈을 안전하게 리팩터링하기

무엇이든 건드리기 전에 모든 호출부를 파악하고, 작업을 체크포인트가 있는 작은 단계로 나누며, 각 단계를 검토하는 동안 테스트를 계속 통과 상태로 유지합니다.

입력 예시

utils/payments.py를 검증, 통화, 결제 게이트웨이별 파일로 나눠 주세요. 기존 import는 모두 그대로 동작해야 해요.

사용 가능코딩과 전체 프로젝트

풀 리퀘스트 리뷰하기

에이전트 팀이 일을 나눕니다. 한 에이전트는 diff에서 버그를 찾고, 다른 에이전트는 엣지 케이스와 네이밍을 확인하며, 코디네이터가 우선순위를 매긴 코멘트 목록 하나로 정리해 드립니다.

입력 예시

feature/export-csv 브랜치의 변경 사항을 리뷰해 주세요. 에러 처리와 기존 데이터를 망가뜨릴 수 있는 부분을 중점적으로 봐 주세요.

사용 가능에이전트 팀

웹 페이지 만들고 확인하기

OPTES가 페이지를 만들고 데스크톱, 태블릿, 휴대폰 크기로 열어 깨지는 부분을 짚어 줍니다. 문제는 클릭 한 번으로 고치거나 다른 방식을 요청할 수 있습니다.

입력 예시

대시보드용 설정 페이지를 다크 모드 토글과 함께 만들어 주세요. 휴대폰 화면에서 넘치는 요소가 없는지도 확인해 주세요.

사용 가능실시간 미리보기

사이드 프로젝트 출시하기

프로젝트가 준비되면 OPTES가 PC에서 웹사이트로 배포합니다. 먼저 비용을 확인하며, 승인하기 전에는 아무것도 공개되지 않습니다.

입력 예시

portfolio 폴더를 웹사이트로 배포해 주세요. 시작하기 전에 비용이 얼마나 드는지 먼저 알려 주세요.

사용 가능원클릭 배포

사용하게 될 기능

  • 사용 가능코딩과 전체 프로젝트프로젝트 구조를 읽고, 코드를 작성하고 테스트하며, 바꾼 내용을 검토합니다.
  • 사용 가능에이전트 팀개발자, 리뷰어, 리서처, 코디네이터가 긴 작업을 나눠 맡습니다.
  • 사용 가능실시간 미리보기만든 결과물이 데스크톱, 태블릿, 휴대폰 크기에서 실행되는 모습을 확인하고, 오류는 클릭 한 번으로 고칩니다.
  • 사용 가능원클릭 배포내 컴퓨터의 프로젝트를 실제 웹사이트로. 비용을 확인하고 승인한 뒤에 진행합니다.

자주 묻는 질문

질문과 답변

OPTES는 프로그래머에게 어떤 도움이 되나요?

프로젝트 폴더 안에서 직접 일합니다. 구조를 읽고, 기존 스타일대로 코드를 작성하고, 테스트를 실행하며, 자신의 변경 사항을 검토합니다. 모든 diff를 직접 보고 무엇을 남기고 무엇을 되돌릴지 결정하면 됩니다.

내 컴퓨터에서 명령을 실행할 수 있나요?

네, 사용자가 선택한 승인 모드 안에서 실행합니다. 명령 가드가 모든 명령을 실행 전에 검사해 파괴적인 명령을 차단하며, 어떤 명령에 명시적인 승인이 필요하고 어떤 명령은 아예 허용하지 않을지 직접 정합니다.

API 키와 비밀번호를 볼 수 있나요?

비밀 정보는 에이전트에게 숨겨지므로, 키를 사용하는 프로젝트에서도 그 값을 읽지 않고 작업할 수 있습니다. 변경 사항이 마음에 들지 않으면 체크포인트로 파일을 되돌리면 됩니다. 수행한 작업은 모두 기록으로 남아 눈앞에서 확인할 수 있습니다.
