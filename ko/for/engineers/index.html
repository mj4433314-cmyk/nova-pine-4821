엔지니어

사무 작업은 맡기고 승인은 직접 하는, 엔지니어를 위한 AI 어시스턴트

OPTES는 엔지니어링 사무 작업 중 번거로운 부분을 맡습니다. 단위가 명확하고 공식이 드러나는 계산 스크립트를 작성하고, 물량산출서(BOQ)를 코드로 만들며, 시방서와 스캔한 도면에서 요구 사항을 추출하고, 현장 보고서와 시공 계획서 초안을 씁니다. 설계를 인증하거나 엔지니어의 판단을 대신하지 않으며, 모든 결과물은 책임 엔지니어가 검토하고 승인합니다.

Windows용 OPTES 다운로드해 드리는 일 보기

Windows 10 및 11 · 64비트

OPTES가 해 드리는 일사용하게 될 기능질문과 답변관련 직업

OPTES가 해 드리는 일

계산 스크립트

계산 내용과 입력값을 설명하세요. OPTES가 모든 변수에 단위를 붙이고 모든 공식을 드러낸 Python 스크립트를 작성해 직접 검산한 예제와 비교 테스트하며, 방법은 엔지니어가 검증합니다.

입력 예시

경간과 하중으로 단순보의 휨과 전단을 검토하는 스크립트를 써 주세요. 공식을 하나하나 보여 주고, 제가 손으로 푼 예제와 비교해 주세요.

사용 가능코딩과 전체 프로젝트

물량산출서(BOQ)

물량 산출 파일을 바탕으로 BOQ를 코드로 만듭니다. 항목 그룹, 단위, 수량, 공종별 합계를 담고, 검토자가 확인할 수 있도록 공식을 드러냅니다.

입력 예시

이 물량 산출을 공종별로 묶은 BOQ로 만들어 주세요. 공종마다 합계를 내고, 단위가 불분명한 항목은 표시해 주세요.

사용 가능코딩과 전체 프로젝트

시방서와 도면 읽기

시방서 PDF나 스캔한 도면을 보내 주세요. 요구 사항, 기재된 주석, 표제란 정보를 목록으로 추출하고, 모호한 부분은 표시합니다.

입력 예시

80쪽짜리 이 시방서에서 콘크리트 피복 두께와 양생에 관한 요구 사항을 모두 뽑아 주세요. 항목마다 쪽 번호도 함께요.

사용 가능이미지와 문서 읽기

기준과 실무 조사

조항이나 공법에 대해 물어보세요. 공개된 자료의 내용을 요약하고, 각 요점을 출처와 연결하며, 판이나 지역 기준에 따라 달라질 수 있는 부분을 짚어 줍니다.

입력 예시

더운 기후에서 긴 콘크리트 슬래브의 신축 이음 간격에 관한 일반적인 실무를 출처와 함께 요약해 주세요.

사용 가능출처가 있는 리서치와 요약

기술 보고서 초안

메모, 결과, 사진을 바탕으로 현장 보고서, 시공 계획서, 진행 보고서 초안을 템플릿 구조에 맞춰 아랍어나 영어로 작성하며, 확인과 서명은 엔지니어가 합니다.

입력 예시

이 메모로 이번 주 진행 보고서를 지난주와 같은 구조로 써 주세요. 본문은 아랍어로, 영어 요약을 붙여서요.

사용 가능글쓰기, 편집, 번역

현장 음성 메모

현장에서 관찰한 내용을 평소 쓰는 방언으로 녹음하세요. OPTES가 텍스트로 옮긴 뒤 관찰 사항, 조치, 담당자를 정리한 목록으로 만듭니다.

입력 예시

오늘 현장 점검 녹음이에요. 관찰 사항 목록으로 정리하고 항목마다 담당자를 지정해 주세요.

사용 가능음성을 텍스트로

사용하게 될 기능

  • 사용 가능코딩과 전체 프로젝트프로젝트 구조를 읽고, 코드를 작성하고 테스트하며, 바꾼 내용을 검토합니다.
  • 사용 가능이미지와 문서 읽기손글씨 아랍어를 포함해 이미지와 스캔한 문서를 읽습니다.
  • 사용 가능출처가 있는 리서치와 요약직접 확인할 수 있는 출처와 함께 자료를 모으고, 요약하고, 비교합니다.
  • 사용 가능글쓰기, 편집, 번역글을 쓰고 다듬고 번역하며, 사용하는 언어나 방언으로 답합니다.
  • 사용 가능음성을 텍스트로타이핑 대신 말하세요. 아랍어 방언을 포함해 말이 텍스트가 됩니다.

자주 묻는 질문

질문과 답변

OPTES는 엔지니어에게 어떤 도움이 되나요?

사무 작업을 맡습니다. 계산 스크립트, 물량산출서, 시방서의 요구 사항 추출, 참고 자료 조사, 보고서 초안, 음성 메모를 회의록으로 정리하는 일까지 돕습니다. 엔지니어링 판단은 엔지니어의 몫입니다.

엔지니어의 판단이나 승인을 대신하나요?

아닙니다. 계산, 문서, 요약을 준비하지만 설계를 인증하거나 승인하지 않습니다. 책임 엔지니어가 방법, 입력값, 결과를 확인하고 모든 결과물을 승인합니다.

엔지니어링 도면을 읽을 수 있나요?

도면과 시방서를 이미지와 문서로서 읽습니다. 주석, 일람표, 표제란, 텍스트 등입니다. 보고한 치수는 활용하기 전에 반드시 원본 도면과 대조해 확인하세요.

아랍어와 영어로 보고서를 쓰나요?

네. 아랍어, 영어, 또는 한 문서에 두 언어를 함께 써서 작성하며, 기술 용어, 기호, 단위를 정확하게 유지합니다. 지시는 현대 표준 아랍어나 평소 쓰는 방언으로 하면 됩니다.
