학생

지름길이 아니라 이해를 쌓아 주는 학생용 AI 어시스턴트

OPTES는 이해하지 못한 수업 내용을 아랍어, 방언, 영어로 더 쉬운 예시와 함께 다른 방식으로 설명합니다. 그런 다음 퀴즈를 내고, 답을 채점하고, 틀린 이유를 설명합니다. 강의 녹음을 요약할 수 있는 텍스트로 바꾸고, 노트 사진을 읽으며, 시험 전 복습 계획을 세웁니다. 목표는 학교의 AI 사용 규정 안에서 스스로 이해하고 익히는 것입니다.

Windows용 OPTES 다운로드해 드리는 일 보기

Windows 10 및 11 · 64비트

OPTES가 해 드리는 일사용하게 될 기능질문과 답변관련 직업

OPTES가 해 드리는 일

수업 내용을 다른 방식으로 설명

이해하지 못한 부분을 말하면 일상적인 예시로 단계별로 설명한 뒤 확인 질문을 합니다. 필요할 때마다 더 쉬운 설명이나 다른 예시를 요청하세요.

입력 예시

미분이 실제로 뭔지 모르겠어요. 일상적인 예시로 단계별로 설명하고, 질문 두 개를 내 주세요

사용 가능글쓰기, 편집, 번역

피드백이 있는 연습 문제

고른 단원에 대해 교육과정 수준에 맞는 문제를 만들고, 답을 채점한 뒤 정답을 바로 알려 주는 대신 틀린 이유를 하나하나 설명합니다. 이해될 때까지 다시 풀어 보세요.

입력 예시

생물 과목 혈액 순환 단원으로 객관식 문제 열 개를 만들어 주세요. 다 풀 때까지 정답은 보여 주지 마세요

사용 가능글쓰기, 편집, 번역

녹음한 강의 요약

녹음이 허용된 강의라면 녹음을 업로드하세요. 텍스트로 옮긴 뒤 핵심 내용과 용어로 정리합니다. 직접 쓴 노트와 비교해 보세요. 출석을 대신하는 것이 아니라 복습을 돕는 도구입니다.

입력 예시

유기화학 강의 녹음이에요. 받아 적은 다음 핵심 용어와 정의 목록을 포함해 요점별로 요약해 주세요

사용 가능음성을 텍스트로

시험 전 복습 계획

시험 날짜, 단원, 공부할 수 있는 시간을 알려 주면 복습 시간과 짧은 퀴즈가 포함된 현실적인 일일 계획을 세웁니다. 진도에 맞춰 조정하세요.

입력 예시

3주 뒤에 물리, 생물, 영어 시험이 있어요. 하루에 네 시간 공부할 수 있어요. 복습 시간표를 짜 주세요

사용 가능글쓰기, 편집, 번역

노트와 교과서 페이지

손으로 쓴 노트나 교과서 페이지를 사진으로 찍으면 읽어서 플래시카드나 문제로 만들어 줍니다. 읽어 낸 텍스트가 원본과 맞는지 확인하세요.

입력 예시

제1차 세계대전에 관한 제 노트 사진으로 앞면은 질문, 뒷면은 답인 플래시카드 스무 장을 만들어 주세요

사용 가능이미지와 문서 읽기

이해하며 배우는 코딩

프로그램이 동작하지 않을 때 바로 고쳐 주기 전에 원인을 설명하고 해결 힌트를 주어, 프로그래머처럼 생각하는 법을 익히게 합니다. 전체 해답은 스스로 시도해 본 뒤에 요청하세요.

입력 예시

제 Python 프로그램이 반복문을 돌 때마다 같은 숫자를 출력해요. 고쳐 주지 말고 어디를 봐야 하는지만 알려 주세요

사용 가능코딩과 전체 프로젝트

사용하게 될 기능

  • 사용 가능글쓰기, 편집, 번역글을 쓰고 다듬고 번역하며, 사용하는 언어나 방언으로 답합니다.
  • 사용 가능음성을 텍스트로타이핑 대신 말하세요. 아랍어 방언을 포함해 말이 텍스트가 됩니다.
  • 사용 가능이미지와 문서 읽기손글씨 아랍어를 포함해 이미지와 스캔한 문서를 읽습니다.
  • 사용 가능출처가 있는 리서치와 요약직접 확인할 수 있는 출처와 함께 자료를 모으고, 요약하고, 비교합니다.
  • 사용 가능코딩과 전체 프로젝트프로젝트 구조를 읽고, 코드를 작성하고 테스트하며, 바꾼 내용을 검토합니다.

자주 묻는 질문

질문과 답변

OPTES는 학생에게 어떤 도움이 되나요?

수업 내용을 여러 방식으로 설명하고, 연습 문제를 만들어 설명과 함께 채점하며, 녹음한 강의를 요약하고, 노트 사진을 읽고, 복습 계획을 세웁니다. 역할은 과제를 대신해 주는 것이 아니라 이해하고 연습하도록 돕는 것입니다.

과제나 연구에 사용해도 되나요?

학교, 대학, 담당 선생님에 따라 다르므로 항상 소속 기관의 AI 사용 규정을 따르세요. 이해하고 연습하고 복습하는 데 활용하고, 자신의 이해를 반영한 결과물을 제출하며, 요청받으면 사용 사실을 밝히세요.

강의를 녹음해서 받아 적어도 되나요?

네, 교수님이나 대학이 녹음을 허용한다면 가능합니다. OPTES가 녹음을 텍스트로 옮기고 요약하지만, 세부 내용과 용어는 수정이 필요할 수 있으니 요약을 노트와 대조해 검토하세요.

방언으로 설명하나요, 현대 표준 아랍어로 설명하나요?

쓰는 방식 그대로 답합니다. 방언으로 물으면 방언으로 답하고, 현대 표준 아랍어를 원하거나 영어로 배우는 과목이라 영어가 필요하면 그렇게 말하기만 하면 됩니다. 필요할 때는 전문 용어를 원래 언어 그대로 둡니다.
