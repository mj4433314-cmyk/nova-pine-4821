건축가

도면을 둘러싼 모든 일을 돕는 건축가용 AI 어시스턴트

OPTES는 도면을 둘러싼 모든 일을 돕습니다. 매스, 재료, 분위기에 대한 설명으로 콘셉트 이미지를 생성하고, 클라이언트 미팅 메모를 명확한 브리프로 정리하며, 면적표를 만들고 갱신하고, 현장 사진을 읽고, 프레젠테이션 문구 초안을 씁니다. 승인되고 날인된 도면은 온전히 건축가의 작업으로 남습니다.

Windows용 OPTES 다운로드해 드리는 일 보기

Windows 10 및 11 · 64비트

OPTES가 해 드리는 일사용하게 될 기능질문과 답변관련 직업

OPTES가 해 드리는 일

설명으로 만드는 콘셉트 이미지

매스, 재료, 분위기를 설명하세요. OPTES가 초기 논의용 콘셉트 이미지를 생성하며, 어떤 방향을 도면으로 발전시킬지는 직접 고릅니다.

입력 예시

제주의 2층 중정형 주택 콘셉트 뷰를 그려 주세요. 현무암 벽, 나무 살창, 깊은 그늘, 저녁 빛으로요.

사용 가능이미지 생성

클라이언트 미팅으로 브리프 작성

미팅 메모를 바탕으로 공간, 우선순위, 예산 메모, 미해결 질문을 담은 명확한 브리프 초안을 작성해, 클라이언트가 확인할 수 있게 준비합니다.

입력 예시

이 메모로 가족 주택 브리프를 써 주세요. 침실 다섯 개, 별도 출입구가 있는 손님용 사랑채, 중정, 그리고 아직 답을 받아야 할 질문까지요.

사용 가능글쓰기, 편집, 번역

면적표

실 목록과 목표 면적을 알려 주세요. 층별, 용도별 합계가 있는 면적표를 만들고, 프로그램이 바뀌면 바로 다시 계산합니다.

입력 예시

이 공간들로 층별 합계가 있는 면적표를 만들어 주세요. 전체가 450제곱미터를 넘으면 알려 주세요.

사용 가능코딩과 전체 프로젝트

현장 사진 읽기

현장 사진과 스케치 평면을 보내 주세요. OPTES가 방위 단서, 주변 건물 높이, 접근로, 기존 상태를 대지 분석용 체크리스트로 정리합니다.

입력 예시

대지를 네 방향에서 찍은 사진이에요. 주변 건물, 접근로, 나무, 다음 방문 때 실측할 것을 대지 분석 메모로 써 주세요.

사용 가능이미지와 문서 읽기

클라이언트 프레젠테이션 문구

프로젝트 스토리, 콘셉트, 보드별 캡션을 클라이언트가 이해하기 쉬운 말로 아랍어나 영어로 쓰며, 문서 전체에서 용어를 일관되게 유지합니다.

입력 예시

클라이언트용 콘셉트 프레젠테이션 문구를 여섯 장으로 써 주세요. 아이디어, 중정, 프라이버시, 빛, 재료, 다음 단계 순서로요.

사용 가능글쓰기, 편집, 번역

프로젝트 소개 페이지

이미지와 문구를 웹 프레젠테이션으로 만들어 데스크톱, 태블릿, 휴대폰 크기에서 확인하고, 비용을 보고 승인한 뒤에만 배포합니다.

입력 예시

콘셉트 이미지와 문구로 주택 프로젝트 소개 페이지를 만들어 주세요. 클라이언트에게 보냈을 때 휴대폰에서도 잘 읽히게요.

사용 가능실시간 미리보기

사용하게 될 기능

  • 사용 가능이미지 생성글로 쓴 설명을 원하는 스타일의 이미지로 만듭니다.
  • 사용 가능글쓰기, 편집, 번역글을 쓰고 다듬고 번역하며, 사용하는 언어나 방언으로 답합니다.
  • 사용 가능코딩과 전체 프로젝트프로젝트 구조를 읽고, 코드를 작성하고 테스트하며, 바꾼 내용을 검토합니다.
  • 사용 가능이미지와 문서 읽기손글씨 아랍어를 포함해 이미지와 스캔한 문서를 읽습니다.
  • 사용 가능실시간 미리보기만든 결과물이 데스크톱, 태블릿, 휴대폰 크기에서 실행되는 모습을 확인하고, 오류는 클릭 한 번으로 고칩니다.

자주 묻는 질문

질문과 답변

OPTES는 건축가에게 어떤 도움이 되나요?

설계를 둘러싼 일을 돕습니다. 논의용 콘셉트 이미지, 클라이언트 메모로 만드는 브리프, 면적표, 현장 사진 메모, 프레젠테이션 문구와 페이지까지 맡습니다. 설계와 그에 관한 결정은 건축가의 몫입니다.

시공 도면이나 날인 도면을 만드나요?

아닙니다. 시공 도면도 날인 도면도 만들지 않으며, 전문가로서의 승인을 대신하지 않습니다. 콘셉트, 브리프, 면적표, 문구 작업을 도울 뿐이며, 도면과 승인은 건축가의 작업이자 책임입니다.

콘셉트 이미지는 정확한 설계인가요?

대화를 여는 분위기와 방향 이미지일 뿐, 치수가 있는 설계가 아닙니다. 초기에 클라이언트와 프로젝트의 방향성을 맞추는 데 활용하고, 선택한 방향은 직접 도면으로 발전시키세요.

아랍 클라이언트에게 알맞은 어조로 쓸 수 있나요?

네. 브리프와 프레젠테이션 문구를 현대 표준 아랍어, 클라이언트에게 친숙한 방언, 또는 영어로 쓰며, 첫 문서부터 마지막 문서까지 건축 용어를 일관되게 유지합니다.
