번역가

초벌은 맡기고 완성은 직접 하는, 번역가를 위한 AI 어시스턴트

OPTES는 제공한 용어집을 따르는 초벌 번역을 만들고, 스캔본과 손글씨 문서를 읽으며, 번역 전에 녹음을 받아 적고, 원문과 번역문 사이의 용어와 숫자가 일관된지 검사합니다. 어조, 정확한 의미, 클라이언트에 대한 책임 같은 번역의 기술은 번역가의 몫으로 남습니다.

용어집을 따르는 초벌 번역

원문과 클라이언트가 승인한 용어집을 업로드하면 그에 맞춘 초벌 번역을 씁니다. 납품 전에 한 문장씩 검토하고 문체를 다듬으세요.

입력 예시

첨부한 용어집을 사용해서 이 상업 계약서를 아랍어로 번역하고, 용어집에 없는 용어는 표시해 주세요

사용 가능글쓰기, 편집, 번역

스캔 문서 읽기

스캔 문서, 증명서, 손으로 쓴 편지를 문단과 항목 순서를 유지한 채 편집 가능한 텍스트로 읽어 냅니다. 번역하기 전에 원본과 대조해 확인하세요.

입력 예시

오래된 손글씨 졸업증명서 사진이에요. 항목 순서를 그대로 유지해서 있는 그대로 텍스트로 옮겨 주세요

사용 가능이미지와 문서 읽기

납품 전 일관성 검사

원문과 번역문을 비교해 일치하지 않는 숫자, 날짜, 이름, 그리고 두 가지 이상으로 번역된 용어를 찾아냅니다. 무엇을 고칠지는 번역가가 정합니다.

입력 예시

영어 원문과 제 번역을 비교해서, 다른 숫자나 날짜, 두 가지로 번역한 용어를 표로 정리해 주세요

사용 가능글쓰기, 편집, 번역

녹음부터 받아 적기

녹음된 인터뷰와 강의를 아랍어 방언까지 포함해 텍스트로 옮겨, 글로 된 원문에서 번역을 시작할 수 있게 합니다. 불분명한 부분은 다시 들어 보세요.

입력 예시

이 레반트 아랍어 녹음을 말한 그대로 받아 적고, 옆 열에 영어 번역을 나란히 붙여 주세요

사용 가능음성을 텍스트로

전문 용어 조사

해당 분야 신조어의 대응어를 찾아 흔히 쓰이는 선택지를 출처와 함께 보여 줍니다. 클라이언트에게 맞는 것을 골라 용어집에 추가하세요.

입력 예시

공식 아랍어 문서에서는 ‘carbon offsetting’의 대응어로 무엇을 쓰나요? 선택지를 출처와 함께 알려 주세요

단어가 아니라 문체를 현지화

걸프나 이라크 시장용 광고처럼 특정 독자에 맞춰 의미는 지키면서 번역을 다시 다듬습니다. 어조와 문화적 표현은 직접 검토하세요.

입력 예시

이 번역을 걸프 시장용 광고로 다듬어 주세요. 사람들이 실제로 말하는 것처럼 친근하게, 하지만 속어는 과하지 않게요

사용 가능글쓰기, 편집, 번역

사용하게 될 기능

  • 사용 가능글쓰기, 편집, 번역글을 쓰고 다듬고 번역하며, 사용하는 언어나 방언으로 답합니다.
  • 사용 가능이미지와 문서 읽기손글씨 아랍어를 포함해 이미지와 스캔한 문서를 읽습니다.
  • 사용 가능음성을 텍스트로타이핑 대신 말하세요. 아랍어 방언을 포함해 말이 텍스트가 됩니다.
  • 사용 가능출처가 있는 리서치와 요약직접 확인할 수 있는 출처와 함께 자료를 모으고, 요약하고, 비교합니다.

자주 묻는 질문

질문과 답변

OPTES는 번역가에게 어떤 도움이 되나요?

반복적인 부분을 맡습니다. 용어집을 따르는 초벌 번역, 스캔 문서 읽기, 녹음 받아 적기, 용어 조사, 일관성 검사까지 돕습니다. 정확한 의미, 문체, 클라이언트에 대한 책임은 번역가의 몫입니다.

공인 번역이나 법률 번역에도 적합한가요?

초벌은 준비할 수 있지만, 공인 번역에는 모든 단어를 검토하고 책임지며 공식 기관의 요건에 따라 서명하는 자격 있는 번역가가 필요합니다. 기계 초벌을 전체 검토 없이 납품하지 마세요.

클라이언트의 기밀 문서는 어떻게 하나요?

작업에 필요한 것만 업로드하고, 클라이언트와의 비밀 유지 계약을 지키며, 가능하다면 업로드 전에 불필요한 개인정보를 지우세요. 무엇을 업로드할지는 언제나 번역가가 결정합니다.

아랍어 방언을 처리하나요?

네. 현대 표준 아랍어와 방언으로 된 텍스트와 녹음을 이해하고, 현대 표준 아랍어나 요청한 특정 방언으로 씁니다. 번역가의 귀가 가장 필요한 지역 관용구와 속담은 항상 직접 검토하세요.
