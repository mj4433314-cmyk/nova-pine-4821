회계사

반복 업무를 맡아 주는 회계사용 AI 어시스턴트

회계사는 수작업 대사, 청구서 입력, 보고서 서식 작업에 많은 시간을 잃습니다. OPTES는 거래 내역을 맞춰 보고 차이를 뽑아내는 스크립트를 작성하고, 청구서 사진을 표로 읽어 내며, 보고서와 고객 서신 초안을 씁니다. 사무와 초안 작업을 위한 어시스턴트이며, 전문가로서의 판단과 최종 승인은 회계사의 몫입니다.

Windows용 OPTES 다운로드해 드리는 일 보기

Windows 10 및 11 · 64비트

OPTES가 해 드리는 일사용하게 될 기능질문과 답변관련 직업
중요

OPTES는 사무와 초안 작업을 위한 어시스턴트이며, 회계사나 감사인을 대신하지 않습니다. 세무 의견이나 세무 판단을 제공하지 않으며, 분개나 재무제표를 승인하지 않습니다. 결정은 자격을 갖춘 회계사가 내리며, 모든 결과물은 반드시 검토해야 합니다. 고객 데이터의 기밀을 유지하고, 필요하지 않은 식별 정보는 삭제하며, 소속 회사의 규정과 직업적 의무를 따르세요.

OPTES가 해 드리는 일

코드로 하는 은행 대사

OPTES가 은행 거래 내역과 원장을 맞춰 보고 차이를 별도 시트에 정리하는 Python 스크립트를 작성합니다. 차이 하나하나를 검토하고 처리 방법은 직접 정하세요.

입력 예시

9월 은행 거래 내역 CSV와 스프레드시트의 분개 내역이 있어요. 금액과 날짜로 맞춰 보고 차이를 정리하는 스크립트를 써 주세요.

사용 가능코딩과 전체 프로젝트

청구서와 영수증 읽기

손으로 쓴 것을 포함해 청구서와 영수증 사진을 읽어 날짜, 공급처, 금액 표로 만듭니다. 입력하기 전에 수치를 확인하세요.

입력 예시

식당 매입 청구서 사진 40장이에요. 날짜, 공급처 이름, 합계 금액을 하나의 표로 뽑아 주세요.

사용 가능이미지와 문서 읽기

월간 경영 보고서 초안

이미 확정한 수치를 바탕으로 변동 사항을 쉬운 말로 설명하는 경영진용 보고서 초안을 만듭니다. 보내기 전에 문구와 숫자를 검토하세요.

입력 예시

이 시트로 3분기 비용에 관한 경영 보고서 초안을 써 주세요. 쉬운 말로, 가장 큰 변동 세 가지를 설명해 주세요.

사용 가능글쓰기, 편집, 번역

고객 서신

누락된 서류를 요청하고 마감일을 알리는 정중하고 명확한 메시지 초안을 씁니다. 검토한 뒤 직접 보내세요.

입력 예시

아직 받지 못한 석 달 치 급여 명세서를 이번 주 안에 보내 달라고 고객에게 요청하는 친절한 메시지를 써 주세요.

사용 가능글쓰기, 편집, 번역

반복적인 데이터 입력

승인하면 OPTES가 검토를 마친 시트의 항목을 클릭과 입력으로 회사 시스템에 옮깁니다. 지켜보다가 언제든 멈출 수 있으며, 입력된 내용을 확인하세요.

입력 예시

이 시트의 항목을 회계 소프트웨어의 비용 입력 화면에 입력해 주세요. 저장할 때마다 먼저 제 승인을 받아 주세요.

사용 가능승인 후 컴퓨터 제어

사용하게 될 기능

  • 사용 가능코딩과 전체 프로젝트프로젝트 구조를 읽고, 코드를 작성하고 테스트하며, 바꾼 내용을 검토합니다.
  • 사용 가능이미지와 문서 읽기손글씨 아랍어를 포함해 이미지와 스캔한 문서를 읽습니다.
  • 사용 가능글쓰기, 편집, 번역글을 쓰고 다듬고 번역하며, 사용하는 언어나 방언으로 답합니다.
  • 사용 가능승인 후 컴퓨터 제어클릭하고, 입력하고, 창 사이를 오가며, 승인 전에는 절대 시작하지 않습니다.

자주 묻는 질문

질문과 답변

OPTES는 회계사에게 어떤 도움이 되나요?

반복적인 사무 작업을 맡습니다. 직접 검토하는 스크립트로 거래 내역을 대사하고, 청구서를 표로 읽어 내며, 보고서와 고객 서신 초안을 씁니다. 전문가로서의 판단과 최종 승인은 회계사의 몫입니다.

OPTES가 세무 의견을 주거나 재무제표를 승인하나요?

아닙니다. OPTES는 어시스턴트이며 회계사를 대신하지 않습니다. 세무 의견이나 세무 판단을 제공하지 않으며, 어떤 분개나 재무제표도 승인하지 않습니다. OPTES가 만드는 모든 것은 자격을 갖춘 회계사가 검토하고 결정할 초안입니다.

고객 기밀은 어떻게 다뤄야 하나요?

작업에 필요한 것만 공유하고, 필요하지 않다면 이름과 계좌번호를 지우며, 회사 규정을 따르세요. OPTES는 비밀번호 같은 비밀 정보를 에이전트에게 숨기고, 수행한 모든 작업은 기록으로 남아 눈앞에서 확인할 수 있습니다.

숫자가 맞는지 어떻게 확인하나요?

OPTES에게 사용한 코드를 보여 주고 원본과 합계를 대사하라고 요청한 뒤, 결과 일부를 직접 표본 검사하세요. 스크립트는 그대로 남아 매달 다시 실행하고 검증할 수 있습니다.
