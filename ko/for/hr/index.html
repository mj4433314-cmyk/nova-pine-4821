인사팀

서류 작업은 맡기고 결정은 직접 하는, 인사팀을 위한 AI 어시스턴트

인사팀은 직무 기술서, 이력서, 근태 파일, 각종 규정에 파묻혀 있습니다. OPTES는 공정한 직무 기술서를 쓰고, 구조화된 면접 질문을 준비하며, 미리 정한 기준에 따라 이력서를 정리하고, 근태 보고서를 코드로 계산합니다. 정보를 정리할 뿐 누구도 평가하지 않으며, 채용과 평가 결정은 언제나 팀의 사람이 내립니다.

Windows 10 및 11 · 64비트

OPTES가 해 드리는 일사용하게 될 기능질문과 답변관련 직업

OPTES가 해 드리는 일

직무 기술서

직무에 실제로 필요한 업무와 자격을 담아, 나이나 성별처럼 직무와 무관한 조건 없이 포용적인 언어로 명확한 직무 기술서를 씁니다. 게시하기 전에 검토하세요.

입력 예시

의약품 유통사의 주니어 회계 담당자 직무 기술서를 써 주세요. 직무에 실제로 필요한 역량에 집중하고, 나이나 성별 조건은 넣지 마세요.

사용 가능글쓰기, 편집, 번역

이력서 정리

이력서를 읽고 미리 정한 기준에 따라 하나의 일관된 표로 정리해 비교를 쉽게 합니다. 누구를 면접할지는 직접 정합니다.

입력 예시

이력서 서른 개를 표로 정리해 주세요. 경력 연수, 채용 공고에 나온 기술, 언어 능력으로요. 지원자 순위를 매기거나 평가하지는 마세요.

사용 가능이미지와 문서 읽기

구조화된 면접 질문

직무 요건과 연결된 질문을 명확한 평가 기준과 함께 준비해, 모든 지원자가 같은 질문과 같은 잣대로 평가받게 합니다.

입력 예시

영업 코디네이터 직무 면접 질문 여덟 개를 준비하고, 질문마다 좋은 답변과 부족한 답변을 가르는 기준을 설명해 주세요.

사용 가능글쓰기, 편집, 번역

직원 핸드북과 규정

경영진의 결정과 메모를 명확하고 잘 정리된 핸드북 챕터로 만듭니다. 채택 전에 경영진과 법률 자문가가 검토합니다.

입력 예시

휴가, 유연 근무, 재택근무에 관한 이 메모를 직원 핸드북의 명확한 한 챕터로 만들어 주세요.

사용 가능글쓰기, 편집, 번역

근태와 휴가 보고서

월별 근태 파일을 합쳐 휴가 잔여일과 지각을 하나의 표로 계산하는 스크립트를 작성합니다. 어떤 조치든 하기 전에 예외 사항은 직접 검토하세요.

입력 예시

12개월 치 근태 파일이 CSV로 있어요. 직원별 휴가 잔여일을 계산하고 검토가 필요한 경우를 표시하는 스크립트를 써 주세요.

사용 가능코딩과 전체 프로젝트

사용하게 될 기능

  • 사용 가능글쓰기, 편집, 번역글을 쓰고 다듬고 번역하며, 사용하는 언어나 방언으로 답합니다.
  • 사용 가능이미지와 문서 읽기손글씨 아랍어를 포함해 이미지와 스캔한 문서를 읽습니다.
  • 사용 가능코딩과 전체 프로젝트프로젝트 구조를 읽고, 코드를 작성하고 테스트하며, 바꾼 내용을 검토합니다.

자주 묻는 질문

질문과 답변

OPTES는 인사팀에 어떤 도움이 되나요?

작성과 정리를 맡습니다. 직무 기술서, 구조화된 면접 질문, 이력서 표, 직원 핸드북, 근태 보고서까지 돕습니다. 채용과 평가 결정은 팀의 몫입니다.

OPTES가 지원자를 고르거나 탈락시키나요?

아닙니다. 직접 정한 직무 관련 기준에 따라 정보를 정리할 뿐, 누구를 합격시키거나 탈락시키는 결정을 내리지 않습니다. 팀의 사람이 모든 지원자의 서류를 검토하고 결정합니다.

채용을 공정하게 유지하려면 어떻게 해야 하나요?

이력서를 읽기 전에 기준을 정해 직무 요건과 연결하고, OPTES에게 나이, 성별, 사진, 결혼 여부를 무시하도록 요청하세요. 결과는 직접 검토하세요. 도구는 도울 뿐 팀의 판단을 대신하지 않습니다.

직원 개인정보는 어떻게 하나요?

작업에 필요한 것만 공유하고, 필요하지 않다면 신분증 번호와 급여는 가리며, 회사 방침을 따르세요. OPTES는 비밀번호 같은 비밀 정보를 에이전트에게 숨기며, 수행한 작업은 기록으로 남아 눈앞에서 확인할 수 있습니다.
