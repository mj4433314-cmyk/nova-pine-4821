게임 개발자

아이디어에서 플레이 가능한 빌드까지, 게임 개발자를 위한 AI 어시스턴트

OPTES는 아이디어와 테스트 사이의 거리를 줄입니다. 세계, 캐릭터, 움직임, 사운드를 갖춘 프로토타입을 만들어 팀의 시간을 투입하기 전에 게임플레이를 직접 느껴 볼 수 있게 하고, 프로젝트 안에서 시스템 코드를 작성하고 고칩니다. 콘셉트 아트와 임시 음악도 생성하고, 퀘스트 텍스트와 대사 초안을 아랍어와 영어로 씁니다.

Windows용 OPTES 다운로드해 드리는 일 보기

Windows 10 및 11 · 64비트

OPTES가 해 드리는 일사용하게 될 기능질문과 답변관련 직업

OPTES가 해 드리는 일

메커닉 프로토타입 만들기

메커닉을 설명하면 OPTES가 세계, 캐릭터 움직임, 사운드를 갖춘 플레이 가능한 프로토타입을 만들어, 아트 팀이 작업을 시작하기 전에 손맛을 테스트할 수 있게 합니다.

입력 예시

작은 탑다운 프로토타입을 만들어 주세요. 좁은 골목을 달리는 배달 스쿠터, 타이머, 시장 노점에 부딪히면 받는 페널티까지요.

사용 가능게임 제작

게임플레이 코드 작성과 수정

프로젝트를 읽고 C++나 엔진의 스크립트 언어로 시스템을 작성한 뒤 테스트합니다. 모든 변경 사항은 수락하거나 되돌릴 수 있는 diff로 전달됩니다.

입력 예시

플레이어가 달리면서 동시에 점프하면 스태미나가 두 번 깎여요. 중복 호출을 찾아서 고쳐 주세요.

사용 가능코딩과 전체 프로젝트

캐릭터와 장소 콘셉트 아트

글로 쓴 브리프를 바탕으로 캐릭터, 소품, 장소의 콘셉트 시트를 생성하고, 아트 리드가 고른 방향으로 다듬어 갑니다.

입력 예시

해 질 녘 아랍 도시 해안도로에 있는 오래된 바닷가 카페의 콘셉트 아트를 세 가지 방향으로 그려 주세요. 따뜻한 조명에, 높은 카메라에서도 잘 읽히게요.

사용 가능이미지 생성

레벨용 임시 음악

OPTES가 레벨이나 메인 메뉴용 음악을 작곡해, 작곡가의 최종 음악이 나오기 전까지 팀이 알맞은 분위기로 플레이테스트할 수 있게 합니다.

입력 예시

야시장 레벨에 쓸 90초짜리 루프 음악을 만들어 주세요. 우드와 가벼운 타악기로, 긴장감은 있지만 무섭지는 않게요.

사용 가능음악

두 언어로 쓰는 대사와 퀘스트 텍스트

짧은 대사, 퀘스트 설명, 아이템 텍스트를 아랍어와 영어로 작성하고, 캐릭터마다 말투를 일관되게 유지하며, UI 박스에 비해 너무 긴 줄은 따로 표시합니다.

입력 예시

해안도로 생선 장수의 대사를 써 주세요. 인사말 다섯 개와 거절 세 개를 가벼운 바스라 방언으로, 영어 버전도 함께요.

사용 가능글쓰기, 편집, 번역

사용하게 될 기능

  • 사용 가능게임 제작아이디어에서 플레이할 수 있는 게임까지. 세계, 캐릭터, 움직임, 사운드.
  • 사용 가능코딩과 전체 프로젝트프로젝트 구조를 읽고, 코드를 작성하고 테스트하며, 바꾼 내용을 검토합니다.
  • 사용 가능이미지 생성글로 쓴 설명을 원하는 스타일의 이미지로 만듭니다.
  • 사용 가능음악내가 만드는 작품을 위해 작곡한 곡.
  • 사용 가능글쓰기, 편집, 번역글을 쓰고 다듬고 번역하며, 사용하는 언어나 방언으로 답합니다.

자주 묻는 질문

질문과 답변

OPTES는 게임 개발자에게 어떤 도움이 되나요?

플레이 가능한 프로토타입을 만들고, 프로젝트 안에서 시스템 코드를 작성하고 고치며, 콘셉트 아트와 임시 음악을 생성하고, 두 언어로 대사 초안을 씁니다. 디자인과 품질에 관한 결정은 팀의 몫입니다.

게임 엔진을 대체하나요?

아닙니다. 엔진과 함께 일합니다. 프로젝트 저장소에서 코드를 작성하고 고치며, 게임 제작 기능으로는 아이디어를 테스트할 프로토타입이나 완성된 소규모 게임을 위한 세계, 캐릭터, 움직임, 사운드를 만듭니다.

OPTES 팀이 만든 예시가 있나요?

네, 이 사이트의 NightDistrict 쇼케이스입니다. OPTES 팀이 Unreal Engine 5로 만든 바닷가 아랍 도시의 해안도로로, 영화 한 편과 직접 걷고 운전할 수 있는 플레이 버전으로 선보입니다.

게임에 자연스러운 아랍어를 써 줄 수 있나요?

네. OPTES는 아랍어에 능숙합니다. 현대 표준 아랍어나 캐릭터에 맞는 방언으로 쓰고, UI 길이를 고려해 아랍어와 영어 사이를 번역하며, 코드는 코드의 언어 그대로 둡니다.
