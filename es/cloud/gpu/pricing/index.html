Lo que incluye cada GPU

  • Una máquina completa: la GPU y su memoria, además de vCPU, RAM y disco que se muestran en la consola antes de iniciar.
  • Facturación por segundo con saldo prepago; para iniciar se necesita saldo para una hora.
  • Jupyter, SSH y plantillas listas (PyTorch, vLLM, ComfyUI).
  • Se detiene sola tras 30 minutos de inactividad o cuando se agota el saldo, con un aviso previo.
  • La consola muestra la disponibilidad de cada GPU antes de elegir.
