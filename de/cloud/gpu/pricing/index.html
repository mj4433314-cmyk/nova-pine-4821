Preise abgerufen am 2026-11-14, berechnet aus dem Live-Katalog; sie können sich mit dem Markt ändern. Abgerechnet wird der Preis, den die Konsole vor dem Start anzeigt.

Was jede GPU mitbringt

  • Eine vollständige Maschine: die GPU und ihr Speicher, dazu vCPU, RAM und Laufwerk, die vor dem Start in der Konsole angezeigt werden.
  • Sekundengenaue Abrechnung über ein Prepaid-Guthaben; ein Start erfordert Guthaben für eine Stunde.
  • Jupyter, SSH und fertige Vorlagen (PyTorch, vLLM, ComfyUI).
  • Stoppt automatisch nach 30 Minuten Leerlauf oder wenn das Guthaben aufgebraucht ist, mit vorheriger Warnung.
  • Die Konsole zeigt die Verfügbarkeit jeder GPU, bevor Sie wählen.

Netzwerklaufwerk für $0.09 pro GB und Monat, das zwischen Sitzungen erhalten bleibt. Das eigene Laufwerk eines Pods kostet $0.129 pro GB und Monat im Betrieb und $0.259 im gestoppten Zustand.
