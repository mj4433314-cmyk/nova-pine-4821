Bei jedem Server enthalten

Ab dem ersten Start aktiv, ohne Einrichtung Ihrerseits.

  • DDoS-SchutzGroße Angriffe werden gefiltert, bevor sie Ihren Server erreichen.
  • Edge- und Host-FirewallEingehender Verkehr wird blockiert, außer was Sie freigeben, und dieselben Regeln gelten auch außerhalb des Servers.
  • SSH nur mit SchlüsselPasswörter und Root-Login sind deaktiviert, und SSH ist standardmäßig auf Ihre Adresse beschränkt.
  • EinbruchsschutzCrowdSec mit einer Community-Sperrliste sperrt Brute-Force-Versuche und bekannte Angreifer.
  • Automatische SicherheitsupdatesTäglich installiert; Sie wählen das Zeitfenster für Neustarts.
  • Port-25-Sperre und Isolierung bei MissbrauchDirekter E-Mail-Versand ist gesperrt, und ein kompromittierter Server wird isoliert, bevor er anderen schadet, während Sie weiterhin Zugriff haben.

Standort und Zahlung

Standort der Server

In Deutschland, in der EU, in zertifizierten Rechenzentren. Etwa 70 ms in den Nahen Osten. Weitere Regionen folgen.

Zahlung

Bestellungen werden aus Ihrem OPTES-Cloud-Guthaben bezahlt, getrennt vom Guthaben Ihres Chat-Tarifs. Aufladen in US-Dollar mit Kryptowährung.
