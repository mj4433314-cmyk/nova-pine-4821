Spezifikationen aller Tarife

In jedem Tarif ohne Aufpreis enthalten.

Betriebssysteme
Ubuntu 24.04 LTS, Ubuntu 26.04 LTS, Ubuntu 22.04 LTS, Debian 13, Debian 12 · Später: Rocky Linux 9, Rocky Linux 10, AlmaLinux 9, AlmaLinux 10, Fedora 43, openSUSE Leap 15.6, Arch Linux
1-Klick-Apps
Docker, Coolify, HestiaCP, WordPress, OpenClaw, Uptime Kuma, OPTES Bots, OPTES CODE (server) · Später: n8n
Sicherheitspaket
DDoS-Schutz, Edge- und Host-Firewall, SSH nur mit Schlüssel, CrowdSec, automatische Sicherheitsupdates, gesperrter Port 25, automatische Isolierung bei Missbrauch, KVM-Isolierung pro Server und Zwei-Faktor-Bestätigung für sensible Aktionen.
Backups
Verschlüsselte tägliche Backups, 7 Tage aufbewahrt, als optionaler Zusatz für $1.85 pro Monat und Server. Snapshots sind in jedem Tarif enthalten. Enthält 50 GB gespeicherte Backups; darüber $0.009 pro GB und Monat.
Traffic
Eingehender Traffic ist kostenlos. Ausgehender Traffic innerhalb des Tarifkontingents nach einer Fair-Use-Richtlinie; darüber hinaus $1.43 pro TB.
Standort
Deutschland (EU) · Etwa 70 ms in den Nahen Osten
Adressen
IPv4 + IPv6
Zugriff und Steuerung
SSH mit Ihrem Schlüssel, eine Browser-Konsole, Ein-/Ausschalten und Neuinstallation, ein Firewall-Editor mit Vorschau, Snapshots und Backups sowie Nutzungsdiagramme.
Support
Per E-Mail an support@optes3.com. Wir prüfen Meldungen so schnell wie möglich.

Abrechnung und Verlängerung

  • Die Verlängerung wird aus Ihrem OPTES-Cloud-Guthaben bezahlt. Ein nicht verlängerter Server wird 2 Tage vor Laufzeitende gekündigt: am 28. Tag eines 30-Tage-Monats und bei 1 oder 2 Jahren Laufzeit 2 Tage vor dem letzten Tag. Eine letzte Erinnerung erhalten Sie 20 Stunden vorher.
  • Verlängern Sie vorher, dann läuft der Server ohne Unterbrechung weiter.
  • Wechseln Sie im Panel in einen höheren Tarif und zahlen Sie nur die Differenz für die verbleibenden Tage.
