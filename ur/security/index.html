سیکیورٹی

کمزوری کی اطلاع دیں

اگر آپ کو optes3.com، OPTES ایپ یا اس کی API میں کوئی سیکیورٹی کمزوری ملے تو سب سے پہلے ہمیں بتائیں۔ ذمہ داری سے اطلاع دینے والوں کے ہم شکر گزار ہیں۔

ہمیں لکھیں: support@optes3.com

آپ کے پیغام میں ہمیں کیا چاہیے

متاثرہ لنک یا حصہ، مسئلہ دوبارہ پیدا کرنے کے مراحل، متوقع اثر، اور کوئی بھی اسکرین شاٹ یا درخواست جو اسے دکھائے۔ پیغام کا عنوان لفظ «Vulnerability» سے شروع کریں۔

ہمارا عہد

ہم آپ کا پیغام ملنے کی تصدیق کرتے ہیں، پانچ کاروباری دنوں میں جواب دینے کی کوشش کرتے ہیں، اور مسئلہ ٹھیک ہونے پر آپ کو بتاتے ہیں۔ نیچے دیے گئے اصولوں پر نیک نیتی سے چلنے والے کے خلاف ہم کوئی کارروائی نہیں کرتے۔

جانچ کے اصول

دوسروں کے ڈیٹا تک رسائی نہ لیں اور نہ اسے بدلیں، سروس میں خلل نہ ڈالیں یا اسے درخواستوں سے نہ بھریں، اور سوشل انجینئرنگ یا جسمانی رسائی استعمال نہ کریں۔ صرف اپنے اکاؤنٹ سے جانچ کریں۔

اشاعت

کوئی بھی تفصیل شائع کرنے سے پہلے ہمیں 90 دن، یا مسئلہ ٹھیک ہونے تک، کا وقت دیں۔ آپ چاہیں تو ہم شکریے میں آپ کا نام لیں گے۔

فائل security.txt میں محققین کے ٹولز کے لیے یہی رابطہ موجود ہے۔ فی الحال ہمارا کوئی شائع شدہ انعامی پروگرام نہیں ہے۔
