ادائیگی کیسے ہوتی ہے؟

عراق سے باہر: امریکی ڈالر میں، کرپٹو کرنسی (USDT، BTC، ETH اور دیگر) میں OxaPay کے ذریعے، اس صفحے پر دکھائی گئی ڈالر قیمت پر۔ عراق میں: عراقی دینار میں، مقامی پیمنٹ گیٹ وے کے ذریعے، فیس شامل۔ دونوں کے قواعد شرائطِ استعمال میں درج ہیں۔

ہر پلان کے ساتھ کون سے ماڈلز ملتے ہیں؟

Lite: OPTES 1.2 Super Lite (ڈیفالٹ)، 1.2 Series Lite، Murphy 1.2.5 Super X Lite، 1.2.1 Flash اور 1.2 Series۔ Pro: یہی۔ Pro 2x اور اس سے اوپر: اوپر والا سب کچھ، ساتھ OPTES 1.2 Super اور MORPHEUS ماڈلز۔ OPTES 1.2.1 Flash، 1.2 Series، 1.2 Super اور MORPHEUS کم درخواستیں مسترد کرتے ہیں، اس لیے یہ بالغوں کے لیے ہیں: یہ صرف اس تصدیق کے بعد کھلتے ہیں کہ آپ کی عمر 18 سال یا اس سے زیادہ ہے۔

ہفتہ وار حد اور ماہانہ کوٹہ کیا ہیں؟

ہفتہ وار حد ایک کوٹہ ہے جو ہر سات دن بعد ایک مقررہ وقت پر نیا ہوتا ہے جو آپ ایپ میں دیکھ سکتے ہیں (مثلاً “ہفتہ 3:00 بجے نیا”)۔ ہفتے بھر اسے اپنی رفتار سے استعمال کریں: پانچ گھنٹے یا روزانہ کی کوئی حد نہیں۔ ماہانہ کوٹہ پورے مہینے کی حد ہے۔ ہر درخواست اتنی ہی گنی جاتی ہے جتنی وہ واقعی استعمال کرتی ہے، اور ایپ ہفتہ وار حد کے 75% اور 90% پر آپ کو بتاتی ہے۔

کوٹہ ختم ہونے پر کیا ہوتا ہے؟

آپ کا کام نہیں رکتا: ہفتہ وار حد یا مہینہ نیا ہونے تک یہ متن اور کوڈ کے لیے ایک ہلکی بیک اپ لین پر، ہفتہ وار حد کے ساتھ، جاری رہتا ہے۔

کیا کوئی مفت آپشن ہے؟

جی ہاں۔ مفت پلان صرف چیٹ کے لیے ہے، فون اور ویب پر، OPTES Fast کے ساتھ: ہفتے میں 420 پیغامات تک، جو ہر ہفتے (سنیچر) کو نئے ہو جاتے ہیں۔ اوپر والے پلانز زیادہ کوٹہ، زیادہ ماڈلز اور ڈیسک ٹاپ ایپ دیتے ہیں۔

کیا پلان میں API شامل ہے؟

Pro+، Max، Max Plus اور Max Ultra میں API تک رسائی شامل ہے۔ اگر آپ کو صرف API چاہیے تو وہ سبسکرپشن کے بغیر، استعمال کے مطابق ادائیگی پر ہی رہتی ہے: ڈویلپرز کی قیمتیں دیکھیں۔

کیا سبسکرپشن منسوخ کی جا سکتی ہے؟

جی ہاں۔ منسوخ کرنے پر آپ کا پلان اس مہینے کے آخر تک فعال رہتا ہے جس کی آپ نے ادائیگی کی ہے۔
