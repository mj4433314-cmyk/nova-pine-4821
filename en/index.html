Clarity before promises

Know what is here.
And what comes next.

OPTES is an independent project. The OPTES 1.2 models are available today on the plans from Lite up, 1.1 is no longer in the menus, and 1.3 is planned, not a capability available today.

Meet OPTES ↗Safety and privacy ↗

Before you begin.

Which version should I choose?+

Start on the web to work in your browser. Choose your desktop version in Downloads. Android is an Alpha release for light use only.

Is OPTES API credit the same as an app subscription?+

The OPTES API has its own wallet, separate from app subscriptions. Review credit and pricing details in the developer platform before adding funds.

Are all models and capabilities available?+

Availability depends on the model, release and account. Check the model status in the OPTES API and the app release notes. The OPTES 1.2 models are available today, by plan, as the plans page shows.
