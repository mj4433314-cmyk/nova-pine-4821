OPTES API for developers

Start in 3 steps

One key, one base URL, every OPTES model. The API speaks the common chat-completions format, so the client you already use works.

Base URLhttps://api.optes3.com/v1
  1. 1

    Get a key

    Sign in with your OPTES account and create a key in one click. The key is shown once, so keep it somewhere safe.

    Get your key

    Requests need credit: top up from $5 on the same page.

  2. 2

    Copy the code

    Put your key in OPTES_API_KEY and run it. That is all.

    curl https://api.optes3.com/v1/chat/completions \
  -H "Authorization: Bearer $OPTES_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "optes-1.2-super-lite",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
    import os, requests

r = requests.post(
    "https://api.optes3.com/v1/chat/completions",
    headers={"Authorization": f"Bearer {os.environ['OPTES_API_KEY']}"},
    json={
        "model": "optes-1.2-super-lite",
        "messages": [{"role": "user", "content": "Hello!"}],
    },
)
print(r.json()["choices"][0]["message"]["content"])
    // Node 18+ or the browser
const r = await fetch("https://api.optes3.com/v1/chat/completions", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.OPTES_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "optes-1.2-super-lite",
    messages: [{ role: "user", content: "Hello!" }],
  }),
});
const data = await r.json();
console.log(data.choices[0].message.content);

    Any chat-completions client works: set the base URL to https://api.optes3.com/v1 and use your key.

  3. 3

    Pick a model

    Click a model and the code above switches to it. Prices in USD per 1M tokens.

    See every model in the dashboard (199, including 190+ without restrictions)

Quick answers

What are the limits?

Each key can have its own daily and monthly spending cap, set in the dashboard. Your account also has a requests-per-minute limit and a monthly spending ceiling; your exact numbers are on the dashboard's Limits page.

When you hit a limit you get 429: wait a moment and try again. Context and the longest reply are on each model card above.

How does billing work?

Prepaid credit in US dollars, no subscription. You pay only for the tokens you use, at the listed price. Top up from $5 in the developer dashboard; you see the final amount and the payment method before you pay.

API credit is separate from OPTES app plans.

Do the models support tools?

Yes. The OPTES models here all support tool calling, streaming and JSON mode.

Endpoints: POST /v1/chat/completions, POST /v1/responses and GET /v1/models.

What do you keep from my requests?

Usage records hold no request or reply text. We keep the numbers only (model, tokens, cost, time, result) to bill you and to show your logs.

A request passes through the servers that run the model so it can be answered. Details in the privacy policy.

My key leaked. What now?

Revoke it in the dashboard in one click and create a new one. Keys start with optes-sk-; if you see one in public, revoke it at once.
