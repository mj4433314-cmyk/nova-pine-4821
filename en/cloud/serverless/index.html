OPTES Cloud · Serverless Launch offer

Serverless

Deploy an inference endpoint on a GPU that wakes on the first request and goes back to zero. You pay for request seconds only.

Order nowCreate an OPTES account

Needs an OPTES account: the same one you use in the app.

How it works

  • Sleeps at zeroNo requests, no GPU cost.
  • Wakes per requestA worker starts on demand; fast boot keeps the wait short.
  • GPU prioritiesOrder the GPUs; we try the first, then the next if it is not available.
  • OPTES keyCall the endpoint with your account key; every request is logged.

What you can run

  • A language-model server with a chat-completions compatible API (vLLM).
  • Image generation through ComfyUI.
  • Speech to text.
  • Any Python worker of your own.

GPU prices are in US dollars, deducted per second from your OPTES Cloud wallet (separate from your chat-plan balance). Top it up in US dollars with cryptocurrency.
