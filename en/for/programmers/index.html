Programmers

An AI assistant for programmers that reads the project before coding

OPTES works inside your project, not in a chat window beside it. It reads the folder structure, follows your naming and conventions, writes the change, runs the tests and reviews its own diff before showing you. Every command passes a guard first, secrets stay hidden from the agent, and checkpoints let you roll any file back.

What OPTES does for you

Fix a failing test

Paste the failure or name the test. OPTES traces the cause through the code, proposes a fix, reruns the suite and shows you the diff to accept or reject.

An example of what you type

test_invoice_totals has failed since yesterday's merge. Find out why and fix it without changing the test itself.

AvailableCoding and full projects

Refactor a module safely

It maps every caller before touching anything, splits the work into small steps with a checkpoint each, and keeps the tests green throughout while you review each step.

An example of what you type

Split utils/payments.py into separate files for validation, currency and payment gateways, and keep every existing import working.

Review a pull request

The agent team divides the work: one agent reads the diff for bugs, another checks edge cases and naming, and the coordinator hands you one prioritised list of comments.

An example of what you type

Review the changes on feature/export-csv. Focus on error handling and anything that could corrupt existing data.

Build and check a web page

FAQ

Questions and answers

How does OPTES help programmers?

It works directly in your project folder: it reads the structure, writes code in your existing style, runs the tests and reviews its own changes. You see every diff and decide what to keep and what to roll back.

Can it run commands on my machine?

Yes, within the approvals mode you choose. A command guard checks every command before it runs and blocks destructive ones, and you decide which commands need your explicit OK and which are not allowed at all.

Does it see my API keys and passwords?

Secrets are hidden from the agent, so it can work on a project that uses keys without reading their values. If you dislike a change, roll the files back to a checkpoint; everything it did stays logged in front of you.
