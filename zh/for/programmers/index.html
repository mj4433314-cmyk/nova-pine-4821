常见问题

问与答

OPTES 如何帮助程序员？

它直接在你的项目文件夹里工作：读懂结构，按你现有的风格写代码，运行测试并审查自己的改动。每处 diff 你都看得到，保留什么、回滚什么由你决定。

它能在我的电脑上运行命令吗？

可以，但要在你选择的审批模式之内。命令防护会在每条命令运行前进行检查，并拦截破坏性命令；哪些命令需要你明确同意、哪些根本不允许执行，都由你决定。

它能看到我的 API 密钥和密码吗？

机密信息对智能体隐藏，所以它可以处理使用密钥的项目，却不会读取密钥的值。如果你不喜欢某个改动，可以把文件回滚到检查点；它做过的一切都会留下记录，摆在你面前。
