常见问题

问与答

OPTES 如何帮助游戏开发者？

它能做出可玩原型，在你的项目中编写和修复系统代码，生成概念图和临时配乐，并用两种语言起草对白。设计和质量方面的决定仍由你的团队来做。

它会取代我的游戏引擎吗？

不会，它与引擎配合使用。它在你的项目仓库中编写和修复代码；而它的游戏制作功能可以构建世界、角色、移动和声音，既能做验证想法的原型，也能做完整的小游戏。

有 OPTES 团队做过的示例吗？

有，就是本网站上的 NightDistrict 展示：一座阿拉伯海滨城市的滨海大道，由 OPTES 团队用 Unreal Engine 5 打造，以一部影片和一个可以步行、驾车的可玩版本呈现。

它能为我的游戏写出自然的阿拉伯语吗？

能。OPTES 精通阿拉伯语：它可以用现代标准阿拉伯语或适合你角色的方言写作，在阿拉伯语和英语之间翻译时会考虑 UI 长度，代码则保持它本来的语言。
