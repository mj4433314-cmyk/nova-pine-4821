OPTES Cloud

从第一分钟起即受保护的 VPS 服务器、按秒计费的 GPU、无服务器推理端点和存储。一个 OPTES 账户，一个控制台。

需要 OPTES 账户，即您在应用中使用的同一个账户。

每台服务器均包含

首次启动即生效，无需您进行任何设置。

  • DDoS 防护大规模攻击会在到达您的服务器之前被过滤。
  • 边缘与主机防火墙除您允许的流量外，入站流量全部阻止，相同规则也在服务器外部生效。
  • 仅密钥 SSH密码登录和 root 登录默认关闭，SSH 默认仅限您的地址访问。
  • 入侵防御CrowdSec 配合社区封禁列表，封禁暴力破解尝试和已知攻击者。
  • 自动安全更新每日安装；重启时间窗口由您选择。
  • 25 端口封禁与滥用隔离直接发信被阻止；被劫持的服务器会在危害他人之前被隔离，您仍保留访问权限。
