面孔

光之面孔

OPTES 做的每一件事，都有一张面孔相伴。面孔上每个数字的亮度，都取自一张原始照片中与它位置完全对应的地方；眼睛和嘴巴不是画出来的，而是在原图中的位置上自然显现。

这张面孔会散成点点光斑，聚成完整的身影，然后再回来。把手移到它上面，它会为你让开。

这一幕此刻正由你的浏览器根据两张照片实时绘制，没有任何五官是手工画上去的。

安全

它能做的越多，决定权就越牢牢握在你手中

凡是可能涉及你的文件、电脑或支出的操作，都会按照你选择的审批模式先经过你；它做过的每一件事都会留下记录，清清楚楚摆在你面前。

审批模式

由你决定哪些操作需要你明确许可、等待多久算超时，以及哪些命令根本不允许执行。

命令防护

它会在每条命令运行前进行检查，并拦截具有破坏性的命令。机密信息对智能体隐藏，检查点保障你的文件安全。

支出上限

你设定一个上限，付费任务到此即停，未经你批准绝不超出。

常见问题

关于 OPTES 的问题

OPTES 是什么？

OPTES（阿拉伯语写作 أوبتس、اوبتس 或 اوبتيس）是一个用你的语言工作的 AI 平台。它是一个不止于回答、而是把工作做完的 AI 智能体：它能编写完整项目并预览运行效果，经你批准后操控你的电脑，生成图像、视频、语音和音乐，还能制作游戏。

OPTES CODE 应用支持哪些系统？如何获取？

它支持 64 位 Windows 10 和 11，安装包约 285 MB。下载链接就在本页顶部的下载卡片中。

OPTES 只是一个编程助手吗？

不是。编程只是其中一部分：它会读懂项目结构，编写、测试，并审查自己改动过的内容。此外还有实时预览、处理长任务的智能体团队、语音转文字、图像和视频生成、语音以及音乐。

它能听懂阿拉伯语及其方言吗？

能。界面从右侧开始，它会用你书写的语言回复：英语、现代标准阿拉伯语或你自己的方言。代码保持它本来的语言。

未经我允许，它会在我的电脑上做任何操作吗？

凡是可能涉及你的文件、电脑或支出的操作，都会按照你选择的审批模式先经过你。命令防护会拦截破坏性命令，检查点保障你的文件安全，支出上限会在达到你设定的额度时停止付费任务。

OPTES 有面向开发者的 AI API 吗？

有。开发者平台通过一个 API 和一个密钥提供十二个 OPTES 模型，涵盖文本、代码、视觉、图像、视频、语音、音乐和搜索。

OPTES 适合哪些人？

所有在电脑前工作的人：程序员、设计师、内容创作者、学生、教师、创业者等等。适用于各行各业页面会具体介绍它能为你的工作做些什么。

如何联系你们或报告安全漏洞？

请发送邮件至 support@optes3.com。有关负责任披露的详细说明，请参阅安全页面。
