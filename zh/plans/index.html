常见问题

关于方案的问题

如何付款？

在伊拉克境外：通过 OxaPay 以加密货币（USDT、BTC、ETH 等）按本页显示的美元价格付款。在伊拉克：通过本地支付网关以伊拉克第纳尔付款，已含手续费。两种方式的规则均见《使用条款》。

每个方案包含哪些模型？

Lite：OPTES 1.2 Super Lite（默认）、1.2 Series Lite、Murphy 1.2.5 Super X Lite、1.2.1 Flash 和 1.2 Series。Pro：同上。Pro 2x 及以上：以上全部，另加 OPTES 1.2 Super 和 MORPHEUS 模型。OPTES 1.2.1 Flash、1.2 Series、1.2 Super 和 MORPHEUS 拒绝的请求更少，因此面向成年人：只有在您确认已年满 18 岁后才会开放。

什么是每周上限和月度额度？

每周上限是每 7 天在固定时间刷新的额度，刷新时间显示在应用中（例如“周六 15:00 刷新”）。一周内可按自己的节奏使用：没有 5 小时或每日上限。月度额度限制整个月。每个请求按实际用量计算，用到每周上限的 75% 和 90% 时，应用会提醒你。

额度用完后会怎样？

工作不会中断：它会在更轻量的备用通道上继续处理文本和代码（有每周上限），直到每周额度或当月额度刷新。

有免费选项吗？

有。免费方案仅限聊天，可在手机和网页上使用 OPTES Fast：每周最多 420 条消息，每周六刷新。上面的方案提供更多额度、更多模型以及桌面应用。

方案包含 API 吗？

Pro+、Max、Max Plus 和 Max Ultra 包含 API 访问。如果你只需要 API，它仍按用量付费，无需订阅：请参阅开发者价格。

可以取消订阅吗？

可以。取消后，你的方案在已付费的当月结束前仍然有效。

轻享版的“仅限手机”是什么意思？

轻享版是聊天方案：用同一个账户，可以在手机应用和网页聊天中使用。不包含电脑应用（智能体和编辑器）、云电脑和视频。你需要通过手机应用订阅；如需电脑应用，请选择 Pro 或更高方案。
