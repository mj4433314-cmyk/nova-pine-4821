隐私政策

本页以通俗易懂的语言说明：我们存储您的哪些信息、哪些内容会离开您的设备、我们与谁共享，以及您可以控制什么。

最后更新：2026年11月15日

我们是谁

OPTES 是一个独立项目。OPTES 由穆罕默德·里亚德运营，并由其依据本政策对您的数据负责。如对您的隐私有任何疑问，或对您的数据有任何请求，请写信至 support@optes3.com。

我们收集什么

  • 您的账户。当您使用 Google 登录时，我们会收到您的电子邮件地址以及您 Google 账户上显示的姓名。我们绝不会收到您的 Google 密码。
  • 我们发送的邮件。我们有时会通过电子邮件发送 OPTES 的新闻和优惠；在任何此类邮件中点击一次退订链接即可停止接收，而服务类邮件（登录验证码、收据）会照常发送。
  • 您的设备。每台设备都有自己的密钥。我们存储的是您设备密钥的哈希值（而非密钥本身），用于将该设备关联到您的账户，并且可以从服务器端停用某台设备。
  • 使用情况。我们记录执行您的方案、限制和额度所需的信息：请求的时间、类型、大小、结果和费用。
  • 付款。以伊拉克第纳尔付款时，您在 Wayl 付款页面上支付；我们绝不会接收或存储您的卡号。如果您以加密货币付款，付款由 OxaPay 处理：我们向其发送金额、方案名称和订单编号（不含您的姓名或电子邮件），它会告知我们付款状态、币种、网络、到账金额和交易哈希。区块链交易本质上是公开的，我们绝不会收到您钱包的私钥或助记词。对于这两种方式，我们都会保留交易记录：金额、状态和编号。
  • 您写给 OPTES 的内容。您请求的文本和您提供的文件会被发送到我们的服务器，再转发给生成回答的模型提供商；否则无法生成回答。
  • 错误报告。如果您从应用发送报告，我们会将其加密存储。
  • AI 回复的举报。如果您点按「举报此回复」，我们会收到举报类别、您的备注，以及（如果「附上回复文本」处于开启状态）该回复的文本，同时还会收到对话的标识符、作答的 OPTES 模型名称、您的账户编号和时间。我们仅将举报用于安全审核和改进回答，并在 90 天内自动删除。
  • 服务器日志。服务器上的运行和安全日志（请求的时间和状态、网络地址以及错误），以便我们发现故障和滥用行为。这些日志会在 30 天内自动删除。另有一份单独的账户事件审计记录（登录、已关联的设备、方案和付款变更），其中不含任何消息文本，并随您的账户一同保留。

语音。当您使用听写、语音消息或语音回复时，录音或文本会到达我们的服务器和一项外部语音服务，以便将其转换为文本或语音。

相机和照片。仅在您选择在应用中发送照片或拍照时使用。

通知。我们保存您设备的通知令牌以推送提醒；您可以在手机设置中关闭通知。

桌面应用

您的对话、文件和项目保存在您自己设备上的本地数据库中。登录令牌通过 Windows 加密（DPAPI，经由 Electron safeStorage）加以保护。目前对话不会同步到我们的服务器；到达我们这里的是您为获得回答而发送的内容，如上文所述。如果我们将来添加可选的同步功能，它只会在您同意后运行，并且我们会在启用前更新本页。

设备索引（桌面应用）

为了让 OPTES 从第一次对话起就理解您的工作，Windows 版 OPTES CODE 桌面应用会在您的电脑上了解您的文件和项目。本节自包含设备索引功能的 OPTES CODE 版本起适用。手机应用和网页版不会索引您的设备。

何时开始。在欧盟和英国，OPTES CODE 会先征求您的同意，只有您同意后才开始索引。在其他所有地区，登录后默认开启，并在首次开启时显示清楚的通知。您可以随时在设置 → 隐私与安全 → 设备索引（Settings → Privacy & security → Device indexing）中关闭。

读取哪些内容。

  • 项目：包含软件或游戏项目的文件夹（例如 git、package.json、Unreal 或 Unity），其编程语言、框架和运行命令，分支和最近一次提交，以及 README 文件的简短摘录。
  • 文档：文件的名称、类型、大小和日期，以及常见文档（txt、md、Word、Excel、PowerPoint、PDF）中的文字，单个文件和文字总量均有大小上限。
  • 照片、视频和音频：仅名称、类型和日期。不分析图片内容。
  • 已安装的程序：名称、版本、发布者和安装日期。
  • 最近打开的文件：Windows“最近使用的项目”列表中的名称和日期，并排除下文列出的所有内容。

绝不读取哪些内容。此清单固定在软件中，任何设置都无法更改：密码和凭据存储；浏览器数据（Cookie、历史记录、已保存的密码）；密码管理器；邮件和消息（Outlook、WhatsApp、Telegram、Signal、Discord、Thunderbird）；.env 和 .ssh 文件、密钥和证书（如 pem、key、p12、pfx）；加密货币钱包；OPTES 自身的文件夹；系统文件夹和程序；以及其他 Windows 账户的文件夹。仅存储在云端的 OneDrive 文件绝不会被下载，只会看到其名称。

保存在哪里。索引仅保存在您的电脑上的 OPTES 数据文件夹中，并经过加密（AES-256-GCM），密钥受您的 Windows 账户保护（DPAPI），因此其他账户或其他电脑无法打开。任何文字在保存前都会去除机密信息（API 密钥、令牌、写下的密码、卡号）。含有针对 AI 的隐藏指令的文件仅作为数据保存，其文字绝不会提供给模型。

哪些内容会离开您的电脑。索引和任何原始文件都不会上传到我们的服务器。当您与 OPTES 对话时，模型可以查询本地索引（搜索您的文件、查看您的项目）。只有简短的答复，例如项目名称、文件路径或已去除机密信息的简短摘录，会成为该对话的一部分，并与其中的任何其他消息一样处理，详见“我们与谁共享数据”。索引数据绝不会用于训练任何模型。

您的选择。

  • 关闭：随时可以关闭，索引会立即停止。
  • 排除文件夹：该文件夹会立即从索引中删除，且不再被读取。
  • “全部忘记”（Forget everything）：从您的电脑上删除索引及其密钥，并关闭索引。您的文件本身不受影响。

共用电脑和工作电脑。索引按每个 Windows 账户分开，绝不会触及其他账户的文件夹。如果这是工作电脑或共用电脑，我们建议您排除不属于您的文件夹，或关闭此功能。如有疑问：support@optes3.com。

网页版

每个账户都有一个独立的工作区，用于保存您的网页版文件和对话，运行在 OPTES 租用的云基础设施上。您的账户、方案、额度和账单在各应用与网页版之间共享。桌面应用的对话和文件保留在您的设备上，目前不与网页版共享。

Android 应用（Google Play）

Google Play 上的 OPTES 应用仅供成年人（18 岁及以上）使用。

对话和文件。您在应用中的对话存储在我们的服务器上，以便您可以再次查看；我们会一直保留这些对话，直到您删除它们或删除您的账户为止（一个很长的对话保留其最近的 600 条消息，一个账户保留其最近的 1,000 个对话）。当您附加文件时，我们的服务器会为模型读取其中的文本：我们不保留上传的文件本身（文件在读取后即被删除，最迟在两天内删除），从中读取的文本会随该对话保留最多 30 天，以便您再次就其提问。OPTES 在对话中为您生成的文件最多保留 30 天。您发送的图片会交给模型以生成回答，不会作为文件存储。

问题日志。应用的问题日志保留在您的手机上，只有当您自己通过「报告问题」以电子邮件发送时，才会到达我们这里。

通知。我们使用 Google 的 Firebase Cloud Messaging 推送通知；它仅接收您设备的通知令牌和通知内容。

默认助理。如果您将 OPTES 设为默认助理，屏幕上的文本只有在您点按以就其提问时才会被发送。

我们与谁共享数据

我们不出售您的数据，也不展示任何广告。我们仅共享运行服务所需的数据，共享对象包括：

  • 第三方 AI 模型提供商：它们接收请求的文本以便作答。OPTES 引擎不会在对话中透露它们的名称。
  • Google，用于登录以及您选择连接的 Google 应用；Wayl 或 OxaPay，用于完成付款。
  • Cloudflare，它为本网站提供服务，并在不使用 Cookie 的情况下统计访问量（Cloudflare Web Analytics）。
  • 运行我们服务器和网页工作区的托管和云服务提供商。
  • 公共机关，如法律要求。

Google 用户数据（Gmail 和 Google Drive）

您可以通过 应用 → 连接 将您自己的 Google 账户连接到 OPTES。在进行任何操作之前，OPTES 会显示它将能够执行的操作，然后 Google 会显示其自己的同意屏幕，由您决定。OPTES 向 Google 申请：

  • 您的 Google 电子邮件地址（openid, email）：用于显示已连接的是哪个 Google 账户。
  • 代表您发送电子邮件（Gmail · gmail.send）：当您提出要求时，OPTES 会在您的对话中以可编辑卡片的形式撰写电子邮件。只有在您亲自按下「发送」时，邮件才会从您的 Gmail 发出，且您有 10 秒钟可以撤销。此权限不允许 OPTES 读取、搜索或删除您邮箱中的电子邮件。
  • 仅限您选择的文件（Google Drive · drive.file）：OPTES 只能打开您在 Google 自己的文件选择器中选取的文件，以及 OPTES 为您创建的文件（例如您要求创建的新表格或文档）。它无法查看您 Drive 中的其他内容。

读取您邮箱的功能（搜索、摘要、回复、归档、重要邮件提醒）目前仅向少数 OPTES 测试账户提供；如果我们向您提供这些功能，Google 将再次征求您的同意，并且本页会事先说明。

我们如何使用这些数据。仅用于为您提供您在对话中要求的功能：撰写并发送您批准的电子邮件，或读取、总结或编辑您选取的文件。为生成回答，该电子邮件或文件的文本会被发送到我们的服务器，再转发给撰写回复的 AI 模型提供商，不作任何其他用途。

我们存储什么以及存储多久。连接令牌在我们的服务器上按账户分别加密保存，并在您断开连接时删除（我们也会请求 Google 撤销这些令牌）。电子邮件卡片在打开期间加密保存（未发送的卡片在 30 分钟后过期），并在发送、取消或过期约一天后删除。为防止群发邮件，我们仅保留收件人地址的单向哈希值，保留两天。我们不保留您 Drive 文件的副本；您询问过的文件中的文本可能会出现在该对话中，而您可以删除该对话。

有限使用（Limited Use）。OPTES 对从 Google API 获得的信息的使用及向任何其他应用的传输，将遵守Google API 服务用户数据政策（Google API Services User Data Policy），包括有限使用（Limited Use）要求。我们只向 AI 模型发送执行您的请求所需的文本，并且不会将您的 Google 数据用于训练模型或广告。我们不会出售这些数据。OPTES 的人员不会阅读这些数据，除非您要求我们这样做（例如为了提供支持）、调查安全或滥用问题需要，或法律要求。

您的控制权。您可以随时通过 应用 → Gmail / Google Drive → 断开连接 断开连接，或在 myaccount.google.com/permissions 移除 OPTES。如需删除我们持有的所有数据，请使用您账户的电子邮箱写信至 support@optes3.com。

我们保留多久

在您的账户存续期间，我们会保留账户和使用数据；在证明付款或出于安全或法律原因需要时，部分数据会保留更长时间。我们不会将任何数据保留超过所需的时间。目前的保留期限如下：

  • Android 应用和网页聊天中的对话：直到您删除它们或删除您的账户为止。
  • 从您附加的文件中读取的文本：最多 30 天；上传的文件本身：最迟在两天内删除；OPTES 为您生成的文件：最多 30 天。
  • AI 回复的举报：在 90 天内自动删除。
  • 服务器日志：在 30 天内自动删除。
  • Gmail 电子邮件卡片和收件人哈希值：如上文 Google 部分所述。
  • 付款记录和账户审计记录：在法律要求的期限内保留。
  • 备份：您的数据会随备份到期而从中移除，最长不超过 3 个月。

当您删除账户时，账户删除页面会说明删除哪些内容以及何时删除。

您的权利：删除、导出、更正

您可以使用与账户关联的电子邮箱写信至 support@optes3.com，或通过账户删除页面，申请获取您的数据副本、更正数据，或删除您的账户及其数据。我们可能会要求您证明该账户属于您。对于依法必须保留的内容（例如付款记录），我们会告知您。

安全

与我们服务器的连接均经过加密。提供商密钥和机密信息保留在服务器上，绝不会到达应用。机密信息对智能体隐藏，应用仅持有一个受限的设备密钥。没有任何系统是绝对安全的；如果您发现漏洞，请通过安全页面联系我们。

儿童

本服务不面向 13 岁以下的任何人，我们不会在知情的情况下收集他们的数据。标有 18+ 的模型和功能仅供年满 18 岁的人使用，并且仅在确认年龄后开放（参见使用条款）。Google Play 上的 OPTES 应用仅供成年人（18 岁及以上）使用。如果您得知有儿童注册了账户，请联系我们，我们将删除该账户。

本政策的变更

如果我们更改本政策，我们会更新页面顶部的日期；对于重大变更，我们会在应用中或通过电子邮件通知您。
