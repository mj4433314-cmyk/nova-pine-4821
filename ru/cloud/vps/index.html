Общие характеристики всех тарифов

Входит в каждый тариф без доплаты.

Операционные системы
Ubuntu 24.04 LTS, Ubuntu 26.04 LTS, Ubuntu 22.04 LTS, Debian 13, Debian 12 · Позже: Rocky Linux 9, Rocky Linux 10, AlmaLinux 9, AlmaLinux 10, Fedora 43, openSUSE Leap 15.6, Arch Linux
Приложения в один клик
Docker, Coolify, HestiaCP, WordPress, OpenClaw, Uptime Kuma, OPTES Bots, OPTES CODE (server) · Позже: n8n
Средства безопасности
Защита от DDoS, пограничный и серверный файрвол, SSH только по ключу, CrowdSec, автоматические обновления безопасности, блокировка порта 25, автоматическая изоляция при злоупотреблениях, изоляция KVM для каждого сервера и двухфакторное подтверждение важных действий.
Бэкапы
Зашифрованные ежедневные резервные копии хранятся 7 дн.; это опция за $1.85 в месяц на сервер. Снимки включены в каждый тариф. Включает 50 GB хранимых копий; сверх этого $0.009 за GB в месяц.
Трафик
Входящий трафик бесплатный. Исходящий — в пределах лимита тарифа по политике честного использования; сверх лимита $1.43 за TB.
Расположение
Германия (ЕС) · Около 70 мс до Ближнего Востока
Адреса
IPv4 + IPv6
Доступ и управление
SSH с вашим ключом, консоль в браузере, питание и переустановка, редактор файрвола с предпросмотром, снапшоты и бэкапы, графики использования.
Поддержка
По почте support@optes3.com. Мы рассматриваем обращения как можно быстрее.

Оплата и продление

  • Продление оплачивается из кошелька OPTES Cloud. Непродлённый сервер отменяется за 2 дня до окончания срока: на 28-й день 30-дневного месяца, а для срока в 1 или 2 года — за 2 дня до последнего дня. Последнее напоминание приходит за 20 часов.
  • Продлите заранее, и сервер продолжит работать без перерыва.
  • Повышайте тариф в панели и платите только разницу за оставшиеся дни.
