イラク国外の方は暗号資産で支払えます：BTC、ETH、USDT など。このページの価格は米ドル表示です。イラク国内：イラク・ディナールの価格。

プランをアップグレード ご契約中の方へ:新しいプランの全額をお支払いいただき、残りのクレジットは引き継がれます。

よくある質問

プランに関する質問

支払い方法は？

イラク国外：OxaPay を通じて暗号資産（USDT、BTC、ETH など）で、このページに表示される米ドル価格でお支払いいただきます。イラク国内：現地の決済サービスを通じてイラク・ディナールで、手数料込みです。どちらのルールも利用規約に記載しています。

各プランで使えるモデルは？

Lite：OPTES 1.2 Super Lite（既定）、1.2 Series Lite、Murphy 1.2.5 Super X Lite、1.2.1 Flash、1.2 Series。Pro：同じモデル。Pro 2x 以上：上記すべてに加えて OPTES 1.2 Super と MORPHEUS モデル。OPTES 1.2.1 Flash、1.2 Series、1.2 Super、MORPHEUS は断るリクエストが少ないため成人向けで、18歳以上であることを確認した後にのみ使えます。

週の上限と月間の枠とは？

週の上限は、アプリに表示される決まった時刻（例：「土 15:00 にリセット」）に7日ごとにリセットされる枠です。1週間の中で自分のペースで使えます。5時間ごとや1日ごとの上限はありません。月間の枠は1か月全体の上限です。各リクエストは実際に使った分だけ数えられ、週の上限の75%と90%に達するとアプリがお知らせします。

枠を使い切るとどうなりますか？

作業は止まりません。週の上限または月の枠がリセットされるまで、テキストとコード向けの軽量な予備レーンで作業が続きます（週ごとの上限あり）。

無料で使う方法はありますか？

はい。無料プランはスマートフォンとウェブでのチャットのみで、OPTES Fast を使います。週に最大420件のメッセージで、毎週土曜日にリセットされます。上のプランでは、より多くの利用枠、より多くのモデル、そしてデスクトップアプリが使えます。

プランに API は含まれますか？

Pro+、Max、Max Plus、Max Ultra には API アクセスが含まれます。API だけが必要な場合は、引き続きサブスクリプションなしの従量課金でご利用いただけます。開発者向け料金をご覧ください。

解約できますか？

はい。解約した場合も、お支払い済みの月の終わりまでプランをご利用いただけます。

ライトの「スマホ専用」とはどういう意味ですか？

ライトはチャット向けのプランです。同じアカウントで、スマホアプリとウェブチャットで使えます。パソコン用アプリ（エージェントとエディター）、クラウドコンピューター、動画は含まれません。お申し込みはスマホアプリから行います。パソコン用アプリを使う場合は、Pro 以上を選んでください。
