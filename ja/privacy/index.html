プライバシーポリシー

このページは平易な言葉で書かれています。当方がお客様について何を保存するか、何がお客様の端末から送信されるか、誰と共有するか、そしてお客様が何を管理できるかを説明します。

最終更新日：2026年11月15日

このページは翻訳です。正本はアラビア語の文書で、次いで英語の文書となります。両者に相違がある場合はアラビア語の文書が優先します。アラビア語または英語でお読みください。

当方について

OPTES は独立したプロジェクトです。OPTES はムハンマド・リヤドが運営しており、同氏が本ポリシーに基づきお客様のデータについて責任を負います。プライバシーに関するご質問やお客様のデータに関するご依頼は、support@optes3.com までご連絡ください。

収集する情報

  • お客様のアカウント。Google でサインインすると、当方はお客様のメールアドレスと、Google アカウントに表示されているお名前を受け取ります。当方がお客様の Google パスワードを受け取ることはありません。
  • 当社からのメール。OPTES のお知らせやキャンペーンをメールでお送りすることがあります。これらのメール内の配信停止リンクを一度クリックすれば停止でき、サービスに関するメール（サインインコード、領収書）は引き続き届きます。
  • お客様の端末。各端末には固有の鍵が割り当てられます。当方は、端末をお客様のアカウントに紐づけるために、端末の鍵そのものではなく鍵のハッシュを保存します。また、端末はサーバー側から無効にすることができます。
  • 利用状況。お客様のプラン、上限、利用枠を適用するために必要な情報を記録します。リクエストが行われた日時、その種類、サイズ、結果、コストです。
  • 支払い。イラク・ディナールの場合、お客様は Wayl の決済ページで支払います。当方がお客様のカード番号を受け取ったり保存したりすることはありません。暗号資産で支払う場合、支払いは OxaPay によって処理されます。当方は同社に金額、プラン名、注文の参照番号（お客様のお名前やメールアドレスではありません）を送り、同社は支払い状況、コイン、ネットワーク、受領額、トランザクションハッシュを当方に通知します。ブロックチェーン上のトランザクションは性質上公開されるものであり、当方がお客様のウォレットの秘密鍵やリカバリーフレーズを受け取ることはありません。いずれの方法でも、当方は取引の記録（金額、状況、参照番号）を保管します。
  • お客様が OPTES に書く内容。リクエストのテキストとお客様が提供したファイルは当方のサーバーに送られ、さらに回答を生成するモデルプロバイダーへ送られます。そうしなければ回答を生成できません。
  • エラーレポート。お客様がアプリからレポートを送信した場合、当方はそれを暗号化して保存します。
  • AI の返答に関する報告。お客様が「この返答を報告」をタップすると、当方は報告のカテゴリ、お客様のメモ、および「返答のテキストを添付」がオンの場合はその返答のテキストを、会話の識別子、回答した OPTES モデルの名前、お客様のアカウント番号、日時とともに受け取ります。当方は報告を安全性の審査と回答の改善にのみ使用し、90日以内に自動的に削除します。
  • サーバーログ。障害や不正利用を見つけるための、サーバー上の運用ログおよびセキュリティログ（リクエストの時刻と状態、ネットワークアドレス、エラー）。これらは30日以内に自動的に削除されます。これとは別に、アカウントイベント（サインイン、連携済みの端末、プランおよび支払いの変更）の監査記録があり、メッセージのテキストは含まず、お客様のアカウントとともに保管されます。

音声。音声入力、ボイスメモ、または音声による返答を使用する場合、録音またはテキストは当方のサーバーと外部の音声サービスに届き、テキストまたは音声に変換されます。

カメラと写真。お客様がアプリで写真を送信すること、または撮影することを選んだ場合にのみ使用されます。

通知。通知を届けるために、お客様の端末の通知トークンを保管します。通知はスマートフォンの設定でオフにできます。

デスクトップアプリ

お客様の会話、ファイル、プロジェクトは、お客様ご自身の端末上のローカルデータベースに保管されます。サインイントークンは Windows の暗号化（DPAPI、Electron safeStorage 経由）で保護されます。現時点では、会話は当方のサーバーと同期されません。当方に届くのは、上記のとおり、回答を得るためにお客様が送信したものです。今後任意の同期機能を追加する場合、それはお客様の同意がある場合にのみ機能し、当方は有効にする前に本ページを更新します。

デバイスのインデックス作成（デスクトップアプリ）

OPTES が最初の会話からお客様の作業を理解できるように、Windows 版デスクトップアプリ OPTES CODE はお客様のコンピューター上でファイルとプロジェクトを把握します。本項は、デバイスのインデックス作成機能を含む OPTES CODE のバージョンから適用されます。スマートフォンアプリとウェブ版は、お客様のデバイスのインデックスを作成しません。

開始のタイミング。欧州連合（EU）と英国では、OPTES CODE がまずお客様に確認し、同意された場合にのみインデックス作成を開始します。その他のすべての地域では、サインイン後に既定でオンになり、初回にわかりやすい通知が表示されます。設定 → プライバシーとセキュリティ → デバイスのインデックス作成（Settings → Privacy & security → Device indexing）からいつでもオフにできます。

読み取る内容。

  • プロジェクト：ソフトウェアやゲームのプロジェクトを含むフォルダー（例：git、package.json、Unreal、Unity）、その言語、フレームワーク、実行コマンド、ブランチと最新のコミット、README ファイルの短い抜粋。
  • ドキュメント：ファイルの名前、種類、サイズ、日付と、一般的なドキュメント（txt、md、Word、Excel、PowerPoint、PDF）内のテキスト。ファイルごとおよびテキスト全体にサイズの上限があります。
  • 写真・動画・音声：名前、種類、日付のみ。画像の内容は分析しません。
  • インストール済みのプログラム：名前、バージョン、発行元、インストール日。
  • 最近開いたファイル：下記の対象を除外したうえで、Windows の「最近使った項目」の一覧にある名前と日付。

決して読み取らない内容。この一覧はソフトウェアに固定されており、どの設定でも変更できません。パスワードと資格情報の保管場所、ブラウザーのデータ（Cookie、履歴、保存されたパスワード）、パスワードマネージャー、メールとメッセージ（Outlook、WhatsApp、Telegram、Signal、Discord、Thunderbird）、.env と .ssh のファイル、鍵と証明書（pem、key、p12、pfx など）、暗号資産ウォレット、OPTES 自身のフォルダー、システムのフォルダーとプログラム、ほかの Windows アカウントのフォルダーです。クラウド上にのみある OneDrive のファイルはダウンロードされず、名前だけが見えます。

保存場所。インデックスはお客様のコンピューター上の OPTES データフォルダーにのみ保存され、お客様の Windows アカウントで保護された鍵（DPAPI）によって暗号化（AES-256-GCM）されているため、ほかのアカウントやほかのコンピューターでは開けません。シークレット（API キー、トークン、書き留められたパスワード、カード番号）は、保存前にあらゆるテキストから取り除かれます。AI に向けた隠れた指示を含むファイルはデータとしてのみ保持され、そのテキストがモデルに渡されることはありません。

コンピューターの外に出るもの。インデックスも元のファイルも、当方のサーバーにアップロードされることはありません。お客様が OPTES と会話するとき、モデルはローカルのインデックスに問い合わせることができます（ファイルの検索、プロジェクトの確認など）。プロジェクト名、ファイルのパス、シークレットを除いた短い抜粋などの短い回答だけがその会話の一部となり、「データの共有先」に記載のとおり、その会話のほかのメッセージと同じように扱われます。インデックスのデータがモデルの学習に使われることはありません。

お客様の選択。

  • オフにする：いつでも可能で、インデックス作成はすぐに止まります。
  • フォルダーを除外する：そのフォルダーは直ちにインデックスから削除され、以後読み取られません。
  • 「すべて忘れる」（Forget everything）：インデックスとその鍵をコンピューターから削除し、インデックス作成をオフにします。お客様のファイル自体には一切触れません。

共有コンピューターと業務用コンピューター。インデックスは Windows アカウントごとに別々で、ほかのアカウントのフォルダーに及ぶことはありません。業務用または共有のコンピューターでは、ご自身のものではないフォルダーを除外するか、この機能をオフにすることをおすすめします。お問い合わせ：support@optes3.com。

ウェブ版

各アカウントには、お客様のウェブ上のファイルと会話が保管される分離されたワークスペースがあり、OPTES が借りているクラウドインフラ上で動作します。お客様のアカウント、プラン、利用枠、請求書は、各アプリとウェブの間で共有されます。デスクトップアプリの会話とファイルはお客様の端末にとどまり、現時点ではウェブと共有されません。

Android アプリ（Google Play）

Google Play の OPTES アプリは成人（18歳以上）専用です。

会話とファイル。アプリ内のお客様の会話は、後で戻って見られるよう当方のサーバーに保存され、お客様がそれを削除するか、アカウントを削除するまで保管されます（非常に長い会話では最新の600件のメッセージが、アカウントでは最新の1,000件の会話が保管されます）。ファイルを添付すると、当方のサーバーがモデルのためにそのテキストを読み取ります。当方はアップロードされたファイル自体を保管せず（読み取り後に削除され、遅くとも2日以内に削除されます）、読み取ったテキストは、お客様が再度それについて質問できるよう、その会話とともに最大30日間保管されます。OPTES が会話の中でお客様のために作成したファイルは、最大30日間保管されます。お客様が送信した画像は、回答のためにモデルに送られ、ファイルとしては保存されません。

問題ログ。アプリの問題ログはお客様のスマートフォンにとどまり、お客様ご自身が「問題を報告」からメールで送信した場合にのみ当方に届きます。

通知。通知の配信には Google の Firebase Cloud Messaging を使用します。同サービスが受け取るのは、お客様の端末の通知トークンと通知の内容のみです。

デフォルトのアシスタント。OPTES をデフォルトのアシスタントに設定した場合、画面上のテキストは、お客様がそれについて質問するためにタップしたときにのみ送信されます。

データの共有先

当方はお客様のデータを販売せず、広告も表示しません。本サービスの運営に必要なものだけを、次の相手と共有します。

  • 第三者の AI モデルプロバイダー：リクエストに回答するため、リクエストのテキストを受け取ります。OPTES エンジンは会話の中でそれらの名前を明かしません。
  • サインインおよびお客様が連携を選んだ Google アプリのための Google、ならびに支払いを完了するための Wayl または OxaPay。
  • 本ウェブサイトを配信し、Cookie を使わずにその訪問数を計測する Cloudflare（Cloudflare Web Analytics）。
  • 当方のサーバーとウェブワークスペースを運用するホスティングおよびクラウドのプロバイダー。
  • 法律で義務付けられている場合は、公的機関。

Google ユーザーデータ（Gmail および Google Drive）

お客様は アプリ → 接続 から、ご自身の Google アカウントを OPTES に連携できます。何かが行われる前に、OPTES はできるようになる内容を表示し、その後 Google が独自の同意画面を表示し、そこでお客様が決定します。OPTES が Google に求めるものは次のとおりです。

  • お客様の Google メールアドレス（openid, email）：どの Google アカウントが連携されているかを表示するため。
  • お客様に代わってメールを送信（Gmail · gmail.send）：お客様が依頼すると、OPTES は会話内に編集可能なカードとしてメールを作成します。メールはお客様ご自身が「送信」を押した場合にのみお客様の Gmail から送信され、10秒以内であれば取り消すことができます。この権限によって、OPTES がお客様のメールボックス内のメールを読んだり、検索したり、削除したりすることはできません。
  • お客様が選んだファイルのみ（Google Drive · drive.file）：OPTES が開けるのは、お客様が Google 自身のファイルピッカーで選んだファイルと、OPTES がお客様のために作成したファイル（たとえば、お客様が依頼した新しいスプレッドシートやドキュメント）のみです。お客様の Drive のそれ以外の内容を見ることはできません。

メールボックスを読み取る機能（検索、要約、返信、アーカイブ、重要なメールの通知）は、現時点では一部の OPTES テストアカウントにのみ提供されています。これらをお客様に提供する場合は、Google が改めてお客様の同意を求め、本ページでも事前にその旨をお知らせします。

利用方法。お客様が会話の中で依頼した機能を提供するためにのみ使用します。すなわち、お客様が承認したメールの作成と送信、またはお客様が選んだファイルの読み取り、要約もしくは編集です。回答を生成するため、そのメールまたはファイルのテキストは当方のサーバーに送られ、さらに返答を作成する AI モデルプロバイダーへ送られます。それ以外の目的には使用しません。

保存する内容と期間。連携トークンは当方のサーバー上でアカウントごとに個別に暗号化され、お客様が連携を解除すると削除されます（当方は Google にもその取り消しを依頼します）。メールカードは開いている間は暗号化して保管され（未送信のカードは30分後に期限切れとなります）、送信、キャンセル、または期限切れの約1日後に削除されます。大量送信を防ぐため、当方は受信者アドレスの一方向ハッシュのみを2日間保管します。当方はお客様の Drive のファイルのコピーを保管しません。お客様が質問したファイルのテキストがその会話に表示されることがありますが、その会話はお客様が削除できます。

限定使用（Limited Use）。OPTES による、Google API から受け取った情報の使用および他のアプリへの転送は、限定使用の要件を含め、Google API サービスのユーザーデータに関するポリシーに準拠します。当方は、お客様のリクエストを実行するために必要なテキストのみを AI モデルに送信し、お客様の Google データをモデルの学習や広告に使用しません。また、それを販売しません。OPTES の人員がそれを読むことはありません。ただし、お客様が依頼した場合（たとえばサポートのため）、セキュリティや不正利用の調査に必要な場合、または法律で義務付けられている場合を除きます。

お客様による管理。アプリ → Gmail / Google Drive → 接続解除 からいつでも連携を解除できます。または、myaccount.google.com/permissions で OPTES を削除することもできます。当方が保有するすべてのデータを削除するには、お客様のアカウントのメールアドレスから support@optes3.com までご連絡ください。

保管期間

当方は、お客様のアカウントが存在する間、アカウントデータと利用データを保管し、支払いを証明するため、またはセキュリティ上もしくは法律上の理由で必要な場合には、その一部をより長く保管します。必要以上に長く保管することはありません。現在の保管期間は次のとおりです。

  • Android アプリおよびウェブチャットの会話：お客様がそれを削除するか、アカウントを削除するまで。
  • 添付したファイルから読み取ったテキスト：最大30日間。アップロードされたファイル自体：遅くとも2日以内に削除。OPTES がお客様のために作成したファイル：最大30日間。
  • AI の返答に関する報告：90日以内に自動的に削除。
  • サーバーログ：30日以内に自動的に削除。
  • Gmail のメールカードと受信者のハッシュ：上記の Google のセクションに記載のとおり。
  • 支払い記録とアカウントの監査記録：法律で義務付けられている期間。
  • バックアップ：お客様のデータは、バックアップの期限切れに伴い、最長でも3か月以内にバックアップから消去されます。

アカウントを削除する際に何がいつ削除されるかは、アカウント削除ページに記載されています。

お客様の権利：削除、エクスポート、訂正

アカウントに紐づくメールアドレスから support@optes3.com 宛てにご連絡いただくことで、またはアカウント削除ページから、データのコピー、訂正、またはアカウントとそのデータの削除を依頼できます。当方は、アカウントがお客様のものであることの証明を求める場合があります。法律により保管が義務付けられているもの（支払い記録など）については、お客様にお知らせします。

セキュリティ

当方のサーバーへの接続は暗号化されています。プロバイダーの鍵とシークレットはサーバー上にとどまり、アプリに届くことはありません。シークレットはエージェントから隠されており、アプリが保持するのは限定的な端末鍵のみです。完全に安全なシステムは存在しません。脆弱性を発見した場合は、セキュリティページを通じて当方にご連絡ください。

子ども

本サービスは13歳未満の方を対象としておらず、当方がその方々のデータを故意に収集することはありません。18+ と表示されたモデルおよび機能は18歳以上の方専用であり、年齢確認の後にのみ利用可能となります（利用規約を参照）。Google Play の OPTES アプリは成人（18歳以上）専用です。子どもが登録したことを知った場合は、当方までご連絡ください。そのアカウントを削除します。

本ポリシーの変更

本ポリシーを変更する場合、当方はページ上部の日付を更新し、重要な変更についてはアプリ内またはメールでお客様にお知らせします。
