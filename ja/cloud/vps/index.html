全プラン共通の仕様

すべてのプランに追加料金なしで含まれます。

オペレーティングシステム
Ubuntu 24.04 LTS, Ubuntu 26.04 LTS, Ubuntu 22.04 LTS, Debian 13, Debian 12 · 今後提供: Rocky Linux 9, Rocky Linux 10, AlmaLinux 9, AlmaLinux 10, Fedora 43, openSUSE Leap 15.6, Arch Linux
ワンクリックアプリ
Docker, Coolify, HestiaCP, WordPress, OpenClaw, Uptime Kuma, OPTES Bots, OPTES CODE (server) · 今後提供: n8n
セキュリティ構成
DDoS 対策、エッジおよびホストファイアウォール、鍵認証のみの SSH、CrowdSec、自動セキュリティ更新、ポート 25 のブロック、不正利用時の自動隔離、サーバーごとの KVM 分離、重要な操作の二要素確認。
バックアップ
暗号化された日次バックアップを 7 日間保管。サーバーごとに月 $1.85 のオプションです。スナップショットは全プランに含まれます。 保存済みバックアップ 50 GB を含みます。超過分は 1 GB あたり月 $0.009。
転送量
受信は無料です。送信はプランの上限内で公正利用ポリシーが適用され、超過分は TB あたり $1.43 です。
所在地
ドイツ（EU） · 中東まで約 70 ms
アドレス
IPv4 + IPv6
アクセスと管理
お客様の鍵による SSH、ブラウザコンソール、電源操作と再構築、プレビュー付きファイアウォールエディター、スナップショットとバックアップ、使用量グラフ。
サポート
メール support@optes3.com。報告はできるだけ早く確認します。

請求と更新

  • 更新料金は OPTES Cloud ウォレットから支払われます。更新されないサーバーは期間終了の 2 日前に解約されます（30 日の月は 28 日目、1 年または 2 年の期間は最終日の 2 日前）。最後のお知らせは 20 時間前に届きます。
  • それまでに更新すれば、サーバーは止まらずに動き続けます。
  • パネルからアップグレードでき、残りの日数分の差額のみをお支払いいただきます。
