OPTES Cloud

OPTES Cloud

起動直後から保護される VPS サーバー、秒単位課金の GPU、サーバーレス推論エンドポイント、ストレージ。1 つの OPTES アカウント、1 つのコンソールで。

今すぐ注文OPTES アカウントを作成

OPTES アカウントが必要です（アプリと同じアカウント）。

すべてのサーバーに含まれるもの

初回起動時から有効で、お客様側での設定は不要です。

  • DDoS 対策大規模な攻撃はサーバーに届く前にフィルタリングされます。
  • エッジおよびホストファイアウォール許可したもの以外の受信通信はブロックされ、同じルールがサーバー外部にも適用されます。
  • 鍵認証のみの SSHパスワード認証と root ログインは無効で、SSH は既定でお客様のアドレスのみに制限されます。
  • 侵入防御CrowdSec とコミュニティブロックリストにより、総当たり攻撃や既知の攻撃者を遮断します。
  • 自動セキュリティ更新毎日インストールされます。再起動の時間帯はお客様が選択できます。
  • ポート 25 のブロックと不正利用時の隔離直接のメール送信はブロックされます。乗っ取られたサーバーは他者に被害を与える前に隔離され、お客様のアクセスは維持されます。

所在地とお支払い

サーバーの所在地

ドイツ（EU 域内）の認証済みデータセンター。中東まで約 70 ms。他のリージョンは今後追加。

お支払い

ご注文は OPTES Cloud ウォレットから支払われます（チャットプランの残高とは別です）。チャージは米ドルで暗号資産により行います。
