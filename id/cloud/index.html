Termasuk di setiap server

Aktif sejak boot pertama, tanpa pengaturan dari sisi Anda.

  • Perlindungan DDoSSerangan besar disaring sebelum mencapai server Anda.
  • Firewall edge dan hostLalu lintas masuk diblokir kecuali yang Anda izinkan, dan aturan yang sama berlaku di luar server.
  • SSH hanya dengan kunciKata sandi dan login root dinonaktifkan, dan SSH dibatasi ke alamat Anda secara default.
  • Pencegahan intrusiCrowdSec dengan daftar blokir komunitas memblokir upaya brute-force dan penyerang yang dikenal.
  • Pembaruan keamanan otomatisDipasang setiap hari; Anda memilih jendela waktu reboot.
  • Blokir port 25 dan isolasi penyalahgunaanPengiriman e-mail langsung diblokir, dan server yang dibajak diisolasi sebelum merugikan pihak lain, sementara akses Anda tetap ada.

Lokasi dan pembayaran

Lokasi server

Di Jerman, di dalam UE, di pusat data tersertifikasi. Sekitar 70 ms ke Timur Tengah. Wilayah lain menyusul.

Pembayaran

Pesanan dibayar dari dompet OPTES Cloud Anda, terpisah dari saldo paket chat. Isi ulang dalam dolar AS dengan kripto.
