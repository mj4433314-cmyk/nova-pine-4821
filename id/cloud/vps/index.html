Spesifikasi yang sama di semua paket

Termasuk di setiap paket tanpa biaya tambahan.

Sistem operasi
Ubuntu 24.04 LTS, Ubuntu 26.04 LTS, Ubuntu 22.04 LTS, Debian 13, Debian 12 · Nanti: Rocky Linux 9, Rocky Linux 10, AlmaLinux 9, AlmaLinux 10, Fedora 43, openSUSE Leap 15.6, Arch Linux
Aplikasi sekali klik
Docker, Coolify, HestiaCP, WordPress, OpenClaw, Uptime Kuma, OPTES Bots, OPTES CODE (server) · Nanti: n8n
Lapisan keamanan
Perlindungan DDoS, firewall edge dan host, SSH hanya dengan kunci, CrowdSec, pembaruan keamanan otomatis, port 25 diblokir, isolasi penyalahgunaan otomatis, isolasi KVM per server, dan konfirmasi dua faktor untuk tindakan sensitif.
Backup
Cadangan harian terenkripsi disimpan 7 hari, sebagai tambahan opsional $1.85 per bulan per server. Snapshot sudah termasuk di setiap paket. Termasuk 50 GB cadangan tersimpan; selebihnya $0.009 per GB per bulan.
Trafik
Trafik masuk gratis. Trafik keluar dalam kuota paket dengan kebijakan penggunaan wajar; di atasnya $1.43 per TB.
Lokasi
Jerman (UE) · Sekitar 70 ms ke Timur Tengah
Alamat
IPv4 + IPv6
Akses dan kontrol
SSH dengan kunci Anda, konsol browser, daya dan pemasangan ulang, editor firewall dengan pratinjau, snapshot dan backup, serta grafik penggunaan.
Dukungan
Lewat e-mail di support@optes3.com. Kami meninjau laporan secepat mungkin.

Penagihan dan perpanjangan

  • Perpanjangan dibayar dari dompet OPTES Cloud Anda. Server yang tidak diperpanjang dibatalkan 2 hari sebelum jangkanya berakhir: pada hari ke-28 dari bulan 30 hari, dan 2 hari sebelum hari terakhir untuk jangka 1 atau 2 tahun. Pemberitahuan terakhir dikirim 20 jam sebelumnya.
  • Perpanjang sebelum itu dan server tetap berjalan tanpa jeda.
  • Tingkatkan paket dari panel dan bayar hanya selisih untuk sisa hari.
